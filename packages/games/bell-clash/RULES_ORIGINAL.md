# 铃铛对决（Ding）bell_clash_v1 — 原版规则基线

## 准入性质

- 本规则集为**原版规则实现**（机制忠实《Ding! 眼急脑快》，2026-08-10 调研），**不复制原版牌表/卡面/文案**。
- 原版身份：HUCH（德国）原版 + 一刻馆中文经销，2–7 人、8+。**机制误判已纠正**：非"图案/颜色抢答"，而是 UNO 式出牌 + 行动短语卡 + 按铃抢回合。
- 证据等级：规则 C 级（高斯Goh 两期实况简介逐字说明 + 析弈讲规则标题）；牌表未获取 → **牌库为平台原创设计**（4 色×数字 1-6 各 1 张 + 每色自编高频易触发短语卡 18 张 = 96 张牌，短语卡占比 75%）。

## 核心机制（数字实现）

1. **发牌**：每人 `handSize` 张（默认 8），先打完手牌者获胜。
2. **出牌（UNO 式）**：打出同颜色或同数字的牌；打不出就摸一张（`draw_card`，摸到可打出的牌自动打出）。
3. **行动短语卡**：牌面印一句话；有人说了/做了牌上内容时，其他玩家可**拍铃**（`ring_bell`）：
   - 拍铃者手中须持有与顶牌同色的短语卡（可打出）→ 拍铃成功，**接管回合**并打出该短语卡。
   - 拍铃者手中无可打出的短语卡 → **错误拍铃罚摸一张并关闭本次窗口**（防止无限罚摸）。
   - 无人拍铃（窗口超时）→ 回合继续到下一位。
4. **获胜**：先打完手牌者获胜。

## 私密信息边界

- 公开视图仅含手牌张数/当前出牌者/弃牌堆顶/按铃窗口/抽牌堆剩余；他人手牌内容不可见。
- 玩家视图含本人手牌（全部卡片，含短语文案）。

## 配置

| 键 | 默认 | 范围 |
|---|---|---|
| `handSize` | 8 | 1–12 |
| `turnSeconds` | 30 | 1–600 |
| `bellSeconds` | 10 | 1–600 |

## 平台裁定项（原版细则未获取，如实标注）

- 牌库为原创设计（原版牌表未获取）。
- 错误拍铃罚摸一张（原版惩罚未确认）。
- 无人拍铃由计时器兜底结算。
- 拍铃成功打出的短语卡不再触发新的按铃窗口（本轮已结算）。
