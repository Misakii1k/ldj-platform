# 铃铛对决（Ding）bell_clash_v1 — 原版规则基线

## 准入性质

- 本规则集为**原版规则实现**（机制忠实《Ding! 眼急脑快》，2026-08-10 调研），**不复制原版牌表/卡面/文案**。
- 原版身份：HUCH（德国）原版 + 一刻馆中文经销，2–7 人、8+。**机制误判已纠正**：非"图案/颜色抢答"，而是 UNO 式出牌 + 行动短语卡 + 按铃抢回合。
- 证据等级：规则 C 级（高斯Goh 两期实况简介逐字说明 + 析弈讲规则标题）；牌表未获取 → **牌库为平台原创设计**（4 色×数字 1-6 各 1 张 + 每色自编高频易触发短语卡 18 张 = 96 张牌，短语卡占比 75%）。

## 核心机制（数字实现）

1. **发牌**：每人 `handSize` 张（默认 8），先打完手牌者获胜。
2. **出牌（UNO 式）**：打出同颜色或同数字的牌；打不出就摸一张（`draw_card`，摸到可打出的牌自动打出）。普通出牌打出短语卡按颜色当普通牌打，不开任何窗口。
3. **拍铃与短语卡**：任何人、任何时候都能拍铃（`ring_bell`）并从手牌亮出一张短语卡（不要求与顶牌同色）：
   - 亮卡后其他在局玩家有 `challengeSeconds`（默认 3 秒）可点质疑（`challenge_vote`）。
   - 质疑数严格过半（`doubts.length * 2 > voters.length`）→ **拍错**：短语卡放回拍铃者手牌原位置，拍铃者罚摸 1 张，回合回到被打断的玩家重新计时。
   - 质疑未过半（或投确认已不可能过半）→ **拍铃成功**：短语卡进弃牌顶，回合交给拍铃者，拍铃者接着正常出牌。
4. **获胜**：先打完手牌者获胜。

## 私密信息边界

- 公开视图仅含手牌张数/当前出牌者/弃牌堆顶/拍铃质疑状态/抽牌堆剩余；他人手牌内容不可见。
- 玩家视图含本人手牌（全部卡片，含短语文案）。

## 配置

| 键 | 默认 | 范围 |
|---|---|---|
| `handSize` | 8 | 1–12 |
| `turnSeconds` | 30 | 1–600 |
| `challengeSeconds` | 3 | 1–30 |

## 平台裁定项（原版细则未获取，如实标注）

- 牌库为原创设计（原版牌表未获取）。
- 质疑投票判定与 3 秒时限为平台裁定（原版靠线下目测与口头反应）。
- 错误拍铃罚摸一张且卡放回手牌（原版惩罚未确认）。
- 摸牌与普通出牌打出的短语卡不开窗口（仅线下拍铃亮出的短语卡进判定）。

## 验收场景（契约测试覆盖）

牌库构建 / 出牌合法性（同色/同数字/短语卡按色）/ 随时拍铃亮卡 / 质疑投票判定 / 提前过半或超时判定 / 拍错放回罚摸 / 拍铃成功接管回合 / 普通出牌不触发判定 / 回合超时兜底 / 先打完手牌获胜 / 隐私边界。
