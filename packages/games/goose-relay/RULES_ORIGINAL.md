# 以鹅传鹅（鹅鹅密令）goose_relay_classic_v1 — 原版规则基线

## 准入性质

- 本规则集为**原版规则实现**（机制忠实《以鹅传鹅》，2026-08-10 调研），**不复制原版卡面/文案/美术**。
- 原版身份：地核桌游（GeoCrew）原创，2021–2022 摩点众筹，5–9 人、5+ 岁、10–20 分钟；官方教学视频存在（BV1jP4y1F7hE）。
- 证据等级：流程 B/C 级（多源交叉：桌游星期六参数、高斯Goh 实况简介、什么值得买教程）；原版含计分系统（细则缺失，平台裁定）。

## 核心机制（数字实现）

1. **角色分配**：头鹅（队列首位，公开）读案情卡；恶鹅 1 只（5–6 人）/2 只（7–9 人）随机保密；其余白鹅。
2. **案情卡**：凶手鹅 + 受害鹅（角色池互异）+ 道具 + 场景，开局随机生成（道具/场景为平台扩展，原版要素未确认）。
3. **静默传递**（`relaySeconds` 默认 30s/节点）：
   - 头鹅读卡后提交自己的演绎（初始即原始案情）。
   - 每位鹅按队列顺序看到上一位的「演绎」，私密提交自己的演绎；未轮到者视图无内容。
   - 恶鹅可故意传错（规则层不强制白鹅忠实）。
   - 超时自动「忠实复述」上一位演绎（头鹅用原始案情）。
4. **讨论**（`discussionSeconds` 默认 60s，可设 0 跳过）：演绎链全公开，线下自由讨论，App 只计时。
5. **指认阶段（原版核心：从末位起逐一指认，直到有人指对）**（`accuseSeconds` 默认 30s/人）：
   - **从最后一人开始**逐一向前指认「凶手鹅 + 受害鹅」，每指认公开对比。
   - **有人指对** → 立即停止，进入投票；
   - **全部指完无人指对** → 恶鹅获胜（"真相长眠"）。
   - 超时视为指错，推进下一个。
6. **投票投恶鹅**（`voteSeconds` 默认 30s）：
   - 投中（并列最高票均为恶鹅）→ **头鹅 + 好鹅获胜**；
   - 投错 → **恶鹅获胜**。
7. **计分（平台裁定，原版含计分但细则缺失）**：白鹅胜 → 头鹅/好鹅 +1、恶鹅 −1；恶鹅胜 → 每只恶鹅 +2、其余 −1；多局累计。

## 私密信息边界

- 传递期：仅头鹅可见原始案情、仅当前传递者可见上一位演绎；其余玩家与观战视角无案情内容。
- 恶鹅身份仅本人可见；讨论起演绎链公开；指认结果随指认公开。
- 终局统一披露：原始案情、演绎链、恶鹅名单、指认记录、投票统计。

## 配置

| 键 | 默认 | 范围 |
|---|---|---|
| `relaySeconds` | 30 | 1–600 |
| `discussionSeconds` | 60 | 0–600（0 = 跳过讨论） |
| `accuseSeconds` | 30 | 1–600 |
| `voteSeconds` | 30 | 1–600 |

## 平台裁定项（原版细则未获取，如实标注）

- 恶鹅数量配置（5–6 人 1 只、7–9 人 2 只）为推广版推断。
- 案情卡含道具/场景为平台扩展。
- 计分规则自定（原版含计分但细则缺失）。
- 讨论为平台节奏设置（原版无固定时限）。
- 数字版传递为文字演绎（原版为肢体比划+鹅叫）。
