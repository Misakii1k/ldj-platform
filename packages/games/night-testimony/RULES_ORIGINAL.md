# 囚徒之夜（暗夜证词）night_testimony_v1 — 原版规则基线

## 准入性质

- 本规则集为**原版规则实现**（机制忠实《囚徒之夜》，2026-08-10 调研），**不复制原版卡面/文案/美术**。
- 原版身份：台湾嘴嘴出版社（3–6 人、20 分钟、13+）；官方产品页明文玩法，官方教学视频存在。证据等级：**A/B 级（五款中证据最扎实）**。
- 罪刑名称为原创表达（纵火/盗窃/伪造/走私/诈骗/绑架），不复制原版罪刑卡文本。

## 核心机制（数字实现）

1. **身份分配**：1 名**狱警**伪装成囚犯潜伏；其余为囚犯，每人私密持有一张**罪行卡**（互异）。
2. **标记**：每人 3 个 YES + 1 个 NO 标记（`YES_COUNT`/`NO_COUNT`）。
3. **问答阶段**（`questionSeconds` 默认 120s）：
   - 任意玩家向另一名玩家提问（`ask`，问题文本自拟——数字版用文字，线下为口头）。
   - 被问者必须用 YES/NO 回答（`answer`）：囚犯按自己罪行如实回答，狱警可以撒谎。
   - **YES 留在公开轨迹**（question+回答者+YES 公开）；**NO 回答完收回**（标记减少，不公开轨迹）。
   - 结束条件：某玩家 YES 用完 **或** 问满 `questionLimit`（默认 5 = 玩家数）→ 进入推理；计时器超时兜底。
4. **推理阶段**（`deductionSeconds` 默认 60s）：从罪行池取一张**未被使用的罪行卡**公开混入，线下辩论（App 只计时）。
5. **票选阶段**（`voteSeconds` 默认 30s）：每人投一名玩家；并列最高票取座位顺序第一（平台裁定）。
6. **结算**：
   - 被票出者是**囚犯**（或无人投票）→ **狱警获胜**。
   - 被票出者是**狱警** → 狱警获得一次猜罪机会：为每名囚犯猜一个罪行；
     **全部正确** → 狱警**单独获胜**；否则 → **囚犯们获胜**。

## 私密信息边界

- 终局前公开视图仅含阶段/玩家/YES 轨迹/已问数/额外罪行卡/是否有待答问题；`wardenId`、`crimes` 不进公开视图。
- 玩家视图含本人身份（是否狱警）、本人罪行卡（狱警为 null）、本人 YES/NO 剩余、轮到自己回答的问题。
- 观战视角不含任何私密信息；终局统一披露（狱警、罪行卡、问答轨迹、猜罪结果）。

## 配置

| 键 | 默认 | 范围 |
|---|---|---|
| `questionSeconds` | 120 | 1–600 |
| `deductionSeconds` | 60 | 1–600 |
| `voteSeconds` | 30 | 1–600 |
| `questionLimit` | 5 | 1–12 |

## 平台裁定项（原版细则未获取，如实标注）

- 数字版提问为玩家自拟文字（原版为问题卡，题库未获取）。
- 并列最高票取座位顺序第一。
- 问答上限默认 = 玩家数（原版"问满 N 问"）。
- 数字版自动判 YES/NO 标记消耗与公开轨迹（原版为实体标记牌）。
- 推理阶段额外罪行卡为随机取未使用罪行（原版"加入一张罪行卡"）。

## 验收场景（契约测试覆盖）

狱警/罪行随机分配 / 3–6 人边界 / 提问-回答流程与标记消耗 / 问答上限与 YES 用完触发推理 / 计时器兜底 / 投票校验与结算（票出囚犯→狱警胜 / 票出狱警→猜罪）/ 猜罪全对单独胜 vs 囚犯胜 / 终局披露与隐私边界。
