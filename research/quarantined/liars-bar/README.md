# 骗子酒馆（Liar's Bar）：资料总览

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为“待确认”，不得静默当作正式规则实现。

## 版本基线
主基线为 Steam 上 Curve Animation 开发/发行的 **Liar's Bar**，2024-10-02 抢先体验发行；快照日期 2026-08-01。官方页此时列四模式：Liar's Deck、Liar's Dice、Liar's Poker、Liar's Slots，并显示 2026-07-03 有 “Liar's Deck Remastered” 更新。实现须绑定构建/规则版本，不能把 2024 初版攻略当当前规则。

## 证据层级

- **A（官方/一手）**：出版方规则书、开发者商店页、官方更新公告；可作为实现基线。
- **B（可靠二手）**：有完整演示、可与 A 级互证的专业资料；用于补充解释。
- **C（线索）**：零售页、媒体短文、玩家视频/社区讨论；只能提示方向，不能单独决定规则。
- **D（设计建议）**：本文为数字平台提出的实现方案，不声称是原版规则。
