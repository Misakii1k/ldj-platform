# 骗子酒馆：数据与状态

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为“待确认”，不得静默当作正式规则实现。

## 证据层级

- **A（官方/一手）**：出版方规则书、开发者商店页、官方更新公告；可作为实现基线。
- **B（可靠二手）**：有完整演示、可与 A 级互证的专业资料；用于补充解释。
- **C（线索）**：零售页、媒体短文、玩家视频/社区讨论；只能提示方向，不能单独决定规则。
- **D（设计建议）**：本文为数字平台提出的实现方案，不声称是原版规则。

## 通用实体
- `Match`：规则版本、模式、座位、阶段、起手、随机承诺、成人内容设置。
- `Player`：角色皮肤、在线/存活、惩罚轨、一次性能力状态。
- `TurnIntent`：出牌/声明/竞价/质疑/Call/Fold/Spin；服务端校验后落日志。
- `Challenge`：被质疑动作、声明、揭示值、真假、输家与惩罚。
- `HazardState`：膛位与子弹、毒药数、Death Spin；客户端不得预知。

## 状态机
- Deck：`DEAL → DECLARE_VALUE → PLAY_OR_CHALLENGE → REVEAL → ROULETTE → RESET/ELIMINATION → WIN_CHECK`。
- Dice：`SECRET_ROLL → BID → RAISE_OR_CHALLENGE → REVEAL_ALL → POISON → NEXT_ROUND/WIN_CHECK`。
- Poker：`DEAL → BETTING → REVEAL_COMMUNITY` 循环，分支 `FOLD_TRIGGER/SHOWDOWN/ALL_IN`。
- Slots：`SPIN → CLAIM → CHALLENGE_WINDOW → REVEAL → SCORE_OR_DEATH_SPIN → EXECUTE_CHECK`。

## 字段与公平
- Deck：桌面点数、手牌、上一手、声明张数、质疑窗口、重置次数。
- Dice：骰面、竞价（数量/点数/类型）、上一竞价者、百搭标记、毒药数。
- Poker：私牌、公共牌、子弹、行动权、技能可用性、All-In。
- Slots：四格结果、公开格、声明、分数、Double Spin、Execute 权限。
- 洗牌/掷骰/膛位/随机处决由服务器安全随机，先承诺后揭示种子。
- 每场固化 `ruleset_id + build_number`；动画非事实源，事件日志才是。
