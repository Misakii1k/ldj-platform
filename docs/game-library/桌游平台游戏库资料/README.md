# 桌游平台游戏库资料

> 文档定位：产品与规则资料索引，不含代码。所有游戏资料均以证据层级标注来源可信度，未确认的规则不得静默当作正式规则实现。

## 平台定位

本游戏库为手机端卡牌桌游平台提供基础资料，覆盖7款游戏从规则、数据模型、交互设计到资产需求的完整分析。每款游戏按其证据成熟度分级，为后续开发提供可靠依据。

## 建议产品路线

| 阶段 | 内容 | 理由 |
|------|------|------|
| MVP 1 | 情书（现代版+经典版） | 规则闭合、无需语音、可验证边界多 |
| MVP 2 | Durian | 复用卡牌、房间、抢答与私密视图 |
| MVP 3 | 伪人测试 | 加入语音、举报、内容治理 |
| MVP 4 | 奶酪大盗 / 以鹅传鹅 | 引入复杂私密频道、视频或主持流程 |
| 暂缓 | Ding、囚徒之夜 | 官方规则和版本信息不足 |

## 证据成熟度总览

| 游戏 | 证据成熟度 | 主要缺口 |
|------|-----------|---------|
| 以鹅传鹅 | 中低 | 指认方式、恶鹅人数、投票细则 |
| Ding | 低 | 无官方说明书、牌表、触发条件 |
| 伪人测试 | 中低 | 伪人数量与选择机制、平票处理 |
| 囚徒之夜 | 低 | 身份名称、组件表、发言顺序 |
| 情书 | 高 | 需锁定目标SKU（16/21张版） |
| 奶酪大盗 | 中 | 帮凶数量、高级角色变体 |
| Durian | 中高 | 猩猩兄弟牌效果、处罚累计算法 |

## 关键原则

1. 规则机制可研究，但不可复制名称、Logo、角色、卡面、题库、音效或规则文本
2. 商业发布应分别核验数字改编权、商标、插画、文案和数据库内容授权
3. 所有未确认的规则细节标记为"待确认"，不得静默当作正式规则实现
4. 服务器权威：洗牌、骰子、角色、目标、投票全部在服务器端执行

## D1 准入状态

本目录是研究资料，不等于产品准入。任何游戏只有在 `compliance/d1/game-admission.json` 中具备完整权利证据、规则审批和 `playable` 状态时，才能进入生产目录或建房入口。永久禁入项目不在本索引、产品目录、搜索、推荐、构建或发布归档中出现；隔离研究资料不得被运行时代码引用。
