## 游戏简介

"以鹅传鹅"是一款基于"传话游戏"变体的社交派对游戏，灵感来自"传声筒"或"肢体版传话"。游戏中的"头鹅"秘密获知一起"鹅圈凶案"的凶手和受害鹅身份，然后通过肢体表演将案情逐棒传递给下一只鹅。白鹅玩家试图忠实还原案情，恶鹅玩家则故意篡改表演，混淆信息。最终全体玩家根据最后传递的结果进行推理和指认。
