# 以鹅传鹅 — 资产需求

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为"待确认"，不得静默当作正式规则实现。

> 证据层级：A = 官方/一手，B = 可靠二手，C = 线索，D = 设计建议

## 1. 数字资产清单

### 1.1 案情卡（Case Card Deck）

| 资产名称 | 数量 | 说明 | 层级 |
|---------|------|------|------|
| 凶手鹅角色卡 | 20+ 张（建议） | 不同鹅角色，如"鹅老大""鹅小妹"等 | D |
| 受害鹅角色卡 | 20+ 张（建议） | 同上，可与凶手鹅共用池 | D |
| 作案工具/方式卡 | 10+ 张（建议） | 如"平底锅""羽毛球拍"等（待确认格式） | C |
| 作案场景卡 | 10+ 张（建议） | 如"在厨房""在健身房"等（待确认格式） | D |

> 实体版通常包含约 50 张案情卡（D 级估算），每张卡包含上述要素的组合。

### 1.2 角色标识

| 资产名称 | 数量 | 说明 |
|---------|------|------|
| 头鹅标识 | 1 个 | 数字版中为头鹅玩家添加特殊标记/特效 |
| 恶鹅标识 | 1–3 个 | 仅恶鹅本人在自己设备上可见的标识 |
| 白鹅标识 | 若干 | 白鹅玩家通用标识 |

### 1.3 UI 资产

| 资产名称 | 说明 |
|---------|------|
| 鹅主题图标 | 游戏 Logo、角色图标、按钮图标 |
| 场景背景 | 游戏各阶段背景（农场、池塘等鹅主题场景） |
| 动画效果 | 角色揭示动画、表演传递动画、结果展示动画 |
| 音效 | 按钮点击、计时器提醒、结果揭晓音效 |

## 2. 视觉风格建议

### 2.1 美术风格

- **风格定位**：卡通/幽默风格，适合全年龄玩家
- **色彩基调**：明亮、温暖，以白色/灰色/橙色为主色调
- **角色设计**：鹅的形象应可爱、夸张、辨识度高

### 2.2 参考风格

| 项目 | 说明 |
|------|------|
| 整体氛围 | 轻松、搞笑、社交派对感 |
| 角色设计 | 不同鹅有鲜明的个性特征 |
| 界面风格 | 简洁清晰，信息层级分明 |

## 3. 权利前置说明

### 3.1 游戏名称权利

- "以鹅传鹅"的名称权利归属待确认
- 不同出版商可能使用不同名称（如"鹅鹅传""传鹅游戏"等变体，待确认）
- 建议在正式使用名称前进行商标检索

### 3.2 机制权利

- 肢体表演传递游戏机制为通用社交游戏机制，通常不受版权保护
- 具体案情卡内容、角色设计、美术素材为可版权元素
- 任何直接复制自现有实体版的内容（如特定案情卡文本）需取得授权

### 3.3 第三方素材

- 若使用实体版游戏的扫描/翻拍素材，需取得版权方授权
- 建议所有美术资产均为原创或使用免版权素材

## 4. 资产依赖关系

`
案情卡池
  ├── 凶手鹅角色（从中随机选1）
  ├── 受害鹅角色（从中随机选1，与凶手不同）
  ├── 作案工具（从中随机选1，可选）
  └── 作案场景（从中随机选1，可选）

角色标识
  ├── 头鹅标记（固定给座位0的玩家）
  ├── 恶鹅标记（秘密分配给被选中的玩家）
  └── 白鹅标记（其余玩家）
`
