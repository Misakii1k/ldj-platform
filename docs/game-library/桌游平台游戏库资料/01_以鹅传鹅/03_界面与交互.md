# 以鹅传鹅 — 界面与交互

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为"待确认"，不得静默当作正式规则实现。

> 证据层级：A = 官方/一手，B = 可靠二手，C = 线索，D = 设计建议

---

## 1. 核心页面

### 1.1 游戏大厅（LOBBY）

| 界面元素 | 说明 | 层级 |
|---------|------|------|
| 房间码/链接 | 展示当前游戏房间标识 | D |
| 玩家列表 | 显示已加入玩家头像/昵称 | D |
| 人数选择 | 5–9 人范围选择器 | B/C |
| 开始按钮 | 房主/主机开始游戏 | D |
| 规则说明入口 | 查看游戏规则 | D |

### 1.2 角色分配页面（ROLE_DEAL）

| 界面元素 | 说明 |
|---------|------|
| 角色揭示动画 | 每位玩家获得自己的角色（头鹅/白鹅/恶鹅） |
| 隐私保护 | 角色仅对本人可见，他人不可窥屏 |
| 确认按钮 | 玩家确认已理解自己的角色 |

### 1.3 头鹅阅读案情（CASE_VIEW）

> 仅头鹅可见，其余玩家屏幕应屏蔽/显示"请闭眼"提示

| 界面元素 | 说明 |
|---------|------|
| 案情卡展示 | 显示凶手鹅、受害鹅、案情描述 |
| 计时器 | 阅读倒计时（建议 30 秒，D 级） |
| 确认准备按钮 | 头鹅确认已记住案情，准备开始表演 |

### 1.4 表演传递（PASSING）

| 界面元素 | 说明 |
|---------|------|
| 当前表演者提示 | 显示"轮到 X 号表演" |
| 观察者提示 | 显示"请观察 X 号的表演" |
| 角色隐私保护 | 仅显示座位号，不显示角色 |
| 传递进度条 | 显示当前传递进度（如 3/8） |
| 完成确认按钮 | 观察者确认已观看完毕 |

### 1.5 指认与投票（ACCUSATION / VOTE）

| 界面元素 | 说明 | 层级 |
|---------|------|------|
| 案情猜测输入 | 玩家选择/输入猜测的凶手和受害鹅 | D |
| 投票面板 | 选择要投出的疑似恶鹅玩家 | D |
| 计时器 | 指认/投票倒计时 | D |
| 确认按钮 | 提交指认/投票结果 | D |

> 指认方式的具体交互取决于是"最后一人指认"还是"倒序逐人指认"（待确认）

### 1.6 结果页面（RESULT）

| 界面元素 | 说明 |
|---------|------|
| 原始案情展示 | 显示原始案情卡内容 |
| 最终传递结果 | 显示最后一人接收到的内容 |
| 逐棒对比 | 可选展示每棒传递的变化（如有录制） |
| 胜负判定 | 宣布获胜阵营 |
| 再来一局按钮 | 重新开始游戏 |

## 2. 交互原则

### 2.1 隐私保护原则

- **角色信息**：仅本人可见，禁止在任何共享界面中暴露
- **案情内容**：仅头鹅可见，其余玩家在传递阶段不应看到案情卡
- **传递过程**：仅当前表演者和观察者之间可见，其余玩家不应旁观

### 2.2 无障碍设计原则

- 提供清晰的视觉提示和文字说明
- 计时器应有视觉 + 听觉双重提醒（D 级建议）
- 按钮和交互元素应足够大，适合移动端触控

### 2.3 公平性保证

- 所有玩家在传递阶段应使用相同版本的界面
- 恶鹅玩家不应获得任何额外信息或界面特权
- 计时器对所有人一致

---

## 3. 页面流转

`
LOBBY
  |-- 开始游戏 --> ROLE_DEAL
                      |-- 角色分配完成 --> CASE_VIEW（仅头鹅）
                      |-- 其他玩家 --> 等待页面（显示"请等待"）
                                            |
                      CASE_VIEW 完成 --> PASSING（逐棒传递）
                                            |
                      PASSING 完成 --> ACCUSATION（指认案情）
                                            |
                      ACCUSATION 完成 --> VOTE（投票投恶鹅，可选）
                                            |
                      VOTE 完成 --> RESULT
                                      |-- 再来一局 --> LOBBY
`

---

## 4. 特殊交互说明

### 4.1 异步/远程模式（待确认）

若游戏在远程设备上进行，表演传递的交互方式需重新设计：

| 方案 | 说明 | 层级 |
|------|------|------|
| 视频录制传递 | 每只鹅录制视频传给下一人 | D |
| 实时视频通话 | 点对点视频表演 | D |
| 图文描述传递 | 用文字/图片描述表演（偏离原版机制） | D |

### 4.2 计时器

- 建议在表演阶段启用计时器，超时自动进入下一环节（D 级）
- 头鹅阅读案情阶段建议 30 秒倒计时（D 级）
- 单人表演阶段建议 15–30 秒倒计时（D 级）
