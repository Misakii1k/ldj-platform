### 缺失信息（需 A 级来源）

- 恶鹅的具体人数与分配规则（5-9 人各人数档）
- 原版计分系统细则
- 案情卡的具体格式与内容要素（是否含工具/场景）
- 各阶段的计时规则
- 官方规则书/规则文字全文
