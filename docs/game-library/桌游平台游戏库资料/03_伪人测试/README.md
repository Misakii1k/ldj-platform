## 游戏简介

《伪人测试》是一款以"身份伪装"为核心的社交推理派对游戏。（证据等级：B）玩家在回答问题的过程中，被秘密指派为"伪人"的玩家必须将隐藏的关键词自然地嵌入回答中，而普通人类玩家则可以通过说谎来干扰判断。游戏的核心张力在于：**伪人试图隐藏身份，人类试图揪出伪人，而所有人都在真假参半的回答中博弈。**

## 三种模式总览

| 模式 | 核心流程 | 适用人数 | 证据等级 |
|------|----------|----------|----------|
| **判官模式** | 判官出题 → 其他人回答 → 判官指认伪人 | 3-12 人 | B/C |
| **高分模式** | 秘密身份 → 回答 → 匿名投票（3 轮累计） | 3-12 人 | B/C |
| **团队模式** | 队长三选一问题 → 分配对方三名出战者身份 → 30 秒准备 → 回答与指认 | 8-12 人（待确认） | B/C |

## 关键术语

| 术语 | 定义 |
|------|------|
| **伪人** | 被秘密分配特殊身份的玩家，需在回答中嵌入隐藏关键词 |
| **人类** | 普通玩家，可通过说谎干扰判断 |
| **判官** | 判官模式中的特殊角色，负责出题并指认伪人 |
| **秘密关键词** | 伪人必须自然嵌入回答中的隐藏词语 |
| **匿名投票** | 高分模式中玩家对可疑对象进行不记名投票 |
| **队长** | 团队模式中每队的临时决策者 |
