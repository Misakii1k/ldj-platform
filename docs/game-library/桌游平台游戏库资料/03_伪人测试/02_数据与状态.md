## 数据模型

### 玩家 (Player)

| 字段 | 类型 | 说明 | 证据等级 |
|------|------|------|----------|
| playerId | String/UUID | 玩家唯一标识 | D |
| nickname | String | 玩家昵称 | D |
| avatar | String (URL) | 玩家头像 | D |
| score | Integer | 当前累计分数 | B/C |
| isActive | Boolean | 是否仍在游戏中 | D |

### 身份 (Identity)

| 字段 | 类型 | 说明 | 证据等级 |
|------|------|------|----------|
| type | Enum: HUMAN / FAKE | 身份类型 | B/C |
| keyword | String | 伪人的秘密关键词（人类为空） | B/C |
| assignedBy | PlayerID | 身份分配者（团队模式中为对方队长） | B/C |

### 回合 (Round)

| 字段 | 类型 | 说明 | 证据等级 |
|------|------|------|----------|
| roundNumber | Integer | 轮次编号 | D |

| judgeId (判官模式) | PlayerID | 当前判官 | B/C |
| question | String | 本轮题目 | B/C |
| answers | Map<PlayerID, String> | 玩家回答记录 | D |
| votes | Map<PlayerID, PlayerID> | 投票记录（投票者 → 被投者） | B/C |
| status | Enum | 回合状态（见状态机） | D |

### 游戏 (Game)

| 字段 | 类型 | 说明 | 证据等级 |

| currentRound | Integer | 当前轮次 | D |

| teamB | List<PlayerID> | 团队模式 B 队成员 | D |

## 状态机设计

### 游戏级状态机

```
[LOBBY] → [PLAYING] → [FINISHED]
    ↑          |
    └──────────┘ (重新开始)
```

| 状态 | 说明 | 证据等级 |
|------|------|----------|
| LOBBY | 等待玩家加入、选择模式 | D |
| PLAYING | 游戏中，流程由具体模式控制 | D |
| FINISHED | 游戏结束，展示结果 | D |

### 回合级状态机（判官模式）

```
[QUESTION] → [ASSIGN_IDENTITY] → [ANSWER] → [JUDGE] → [SCORE] → [NEXT_ROUND]
```

| 状态 | 说明 | 证据等级 |
|------|------|----------|
| QUESTION | 判官出题 | B/C |
| ASSIGN_IDENTITY | 分配身份（人类/伪人）及关键词 | B/C |
| ANSWER | 非判官玩家依次回答 | B/C |
| JUDGE | 判官指认伪人 | B/C |
| SCORE | 结算分数 | B/C |
| NEXT_ROUND | 进入下一轮 | D |

### 回合级状态机（高分模式）

```
[ASSIGN_IDENTITY] → [ANSWER] → [VOTE] → [SCORE] → [NEXT_ROUND]
```

| 状态 | 说明 | 证据等级 |
|------|------|----------|
| ASSIGN_IDENTITY | 分配秘密身份 | B/C |
| ANSWER | 玩家依次回答问题 | B/C |
| VOTE | 匿名投票 | B/C |
| SCORE | 结算分数 | B/C |
| NEXT_ROUND | 进入下一轮（共3轮） | B/C |

### 回合级状态机（团队模式）

```
[TEAM_QUESTION] → [ASSIGN_OPPONENT] → [PREPARE] → [ANSWER] → [JUDGE] → [SCORE] → [NEXT_ROUND]
```

| 状态 | 说明 | 证据等级 |
|------|------|----------|
| TEAM_QUESTION | 队长从三题中选一题 | B/C |
| ASSIGN_OPPONENT | 队长为对方出战者分配身份 | B/C |
| PREPARE | 30 秒准备时间 | B/C |
| ANSWER | 出战者依次回答问题 | B/C |
| JUDGE | 对方指认 | B/C |
| SCORE | 结算分数 | B/C |
| NEXT_ROUND | 进入下一轮 | D |
