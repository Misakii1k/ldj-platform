## 资产格式要求

| 资产类型 | 推荐格式 | 备注 |
|----------|----------|------|
| 图片 | PNG / SVG | PNG 用于复杂图形，SVG 用于图标/简单图形 |
| 动画 | Lottie JSON / GIF | Lottie 推荐（更小、可缩放） |
| 音频 | MP3 / AAC | 建议使用高质量 128kbps+ |
| 字体 | WOFF2 / TTF | WOFF2 优先（更小） |
