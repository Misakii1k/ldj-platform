## 交互原则

### 原则 1：身份保密优先

- 身份信息在任何情况下都不应被其他玩家看到（证据等级：B/C）。
- 身份卡使用**长按揭示**机制，松手即隐藏（证据等级：D）。
- 建议在手机/设备上增加防窥膜或角度限制提示（证据等级：D）。

### 原则 2：匿名性保障

- 投票过程必须匿名，不显示投票者的身份（证据等级：B/C）。
- 投票结果只显示票数分布，不显示谁投了谁（证据等级：D）。
- 如使用 APP，建议使用设备本地震动反馈代替屏幕提示（证据等级：D）。

### 原则 3：操作确认

- 关键操作（投票、指认、确认身份查看）应有二次确认（证据等级：D）。
- 投票后应有一定时间（如 3 秒）的更改窗口，超时锁定（证据等级：D）。

### 原则 4：公平性

- 所有玩家在同一时间获得身份信息（证据等级：D）。
- 回答顺序应随机或按固定顺序轮换，避免因顺序产生不公平优势（证据等级：D）。

## 页面流转

### 判官模式页面流转

```
大厅 → 身份分配(所有人) → 判官出题页 → 答题页(依次回答)
     → 指认页(判官) → 结算页 → 下一轮/结束
```

### 高分模式页面流转

```
大厅 → 身份分配(所有人) → 答题页(依次回答)
     → 投票页(匿名) → 结算页 → 下一轮(x3)/结束
```

### 团队模式页面流转

```
大厅 → 分队 → 队长出题页 → 对方身份分配页(队长)
     → 准备页(30秒) → 答题页(出战者依次回答)
     → 指认页(对方队伍) → 结算页 → 下一轮/结束
```
