# Sources

## 来源分级

| 级别 | 定义 | 使用方式 |
|---|---|---|
| A | 出版商官网、正式规则书、官方 FAQ | 可支持“官方”结论 |
| B | BoardGameGeek 条目、发行商商品页、可靠媒体教学 | 用于交叉核对，不单独裁定争议 |
| C | 商店文案、玩家视频、论坛与二手规则摘要 | 仅用于发现问题和变体 |

## 已采用资料

1. Jolly Thinkers / Broadway Toys 的《Cheese Thief》产品与规则资料。应优先取得与拟上线地区、语言、发行年份一致的规则书原件。当前检索未获得可稳定引用的官方规则全文，因此本目录把无法核实的票制和特殊人数规则列为待确认。
2. BoardGameGeek 的 Cheese Thief 条目及其文件、论坛板块。可用于核对设计者、人数、时长、组件和玩家争议，但用户上传文件与论坛回答不等同于官方裁定。
3. 实体教学和玩家规则摘要。仅用于理解“骰点决定醒来时刻、同点互相目击、单独醒来可能盗取奶酪”的核心流程，不用来裁决平票和胜负边界。

## 引用原则

本文档没有复制规则书长段原文，而是以产品需求语言重新组织机制。任何标记为“官方核心”的条目，在上线前仍应由项目方持有的正式规则书复核。若正式规则与本目录冲突，以目标发行版正式规则为准，并在本文件记录修订日期与依据。

## 待补齐的直接来源

- 目标中文或英文版规则书的封面、版本号和完整页码。
- 出版商针对“无人偷到奶酪、平票、低人数”的 FAQ。
- 盒内组件清单及不同印次差异。
- 中文译名与数字发行相关授权证明。
