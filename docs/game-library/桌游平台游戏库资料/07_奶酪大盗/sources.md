## 引用原则

本文档没有复制规则书长段原文，而是以产品需求语言重新组织机制。标记为”原版基线”的条目基于上述 A/B/C 级来源交叉验证；仍无法核实的条目（如整夜未盗胜负、官方规则书全文）在规则文档与准入台账中如实标注为平台裁定，不冒充官方。
