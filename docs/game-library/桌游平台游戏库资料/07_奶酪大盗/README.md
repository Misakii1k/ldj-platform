# 奶酪大盗

## 文档定位

本目录把《奶酪大盗》（Cheese Thief）整理为适合线上桌游平台制作、评审和验收的中文资料。游戏的核心是“闭眼夜晚 + 骰子决定醒来时刻 + 目击信息 + 白天讨论指认”。本文档不包含程序实现。

## 资料标签

- **官方**：可由出版规则、组件说明或官方产品信息直接支持的内容。
- **变体**：玩家社群、不同版本或平台可能采用，但不能默认视为原版规则的内容。
- **建议**：为线上化、易用性、无障碍或防作弊提出的产品方案，需项目方确认。
- **待确认**：现有资料不足、不同版本可能不一致，开发前必须锁定的事项。

## 游戏概览

| 项目 | 内容 |
|---|---|
| 类型 | 社交推理、隐藏信息、短局派对游戏 |
| 主题 | 老鼠们夜间争夺奶酪，并在天亮后寻找小偷 |
| 常见人数 | 4–8 人；不同发行资料对最低人数可能有差异 |
| 单局时长 | 约 10–15 分钟，取决于讨论时长 |
| 核心物件 | 每人一颗六面骰、遮蔽骰子的容器或等价界面、中央奶酪标记 |
| 核心信息 | 自己的醒来时刻、同一时刻醒来的玩家、奶酪是否已被盗 |
| 胜负结构 | 小偷隐藏身份；其他玩家依靠目击链与发言完成指认 |

## 产品边界

首版应忠实保留三件事：玩家不能看到别人的骰点；玩家只在自己的时刻获得夜间信息；白天信息主要依赖玩家陈述而非系统替其推理。系统可以防止非法操作、记录流程并辅助理解，但不应自动公开“谁看见了谁”或给出逻辑答案。

观战、录像、复盘、断线重连、语音房及举报属于平台能力。它们会接触隐藏信息，必须服从本游戏的可见性规则，不能让在局玩家通过旁观账户、回放时间轴或通知预览获取答案。
