# 04 资产需求

## 1 视觉方向

主题建议采用温暖夜色、木质餐桌、老鼠洞与奶酪元素，气氛偏俏皮推理而非恐怖。若使用原版名称、角色造型、包装图、图标或插画，必须取得相应授权；未获授权时需制作原创视觉体系，不能临摹官方画风。

## 2 必需视觉资产

| 类别 | 资产 | 状态与规格建议 |
|---|---|---|
| 标识 | 中文名、英文名组合标识 | 横版、方形图标、深浅底版本 |
| 骰子 | 六面骰 1–6 | 大图、缩略图、读屏文本；静止与掷出状态 |
| 骰杯 | 关闭、摇动、揭开 | 避免通过杯子差异暗示点数 |
| 奶酪 | 桌面、被取走、结算高亮 | 至少 3 状态；小尺寸仍可辨识 |
| 玩家 | 4–8 个原创老鼠头像或通用头像框 | 正常、当前醒来、断线、已投票 |
| 场景 | 夜晚桌面、闭眼遮罩、天亮桌面 | 宽屏与移动端裁切安全区 |
| 时间 | 1–6 点时刻标识 | 数字为主，钟表图形为辅 |
| 结算 | 时间轴节点、目击连线、小偷徽记 | 能同时容纳 8 名玩家 |

## 3 动效

- 掷骰：0.6–1.0 秒，减少动态模式可直接切结果。
- 夜幕：统一长度淡入，不能因醒来人数变化。
- 醒来：私密聚光或睁眼动效，200–400 毫秒。
- 偷奶酪：轻量滑入个人区域，不显示给闭眼玩家。
- 天亮：全房一致的光照变化。
- 结算：按 1–6 点逐步揭示，每步可跳过但不影响数据完整性。

## 4 音频

需要夜晚环境循环、时刻提示、私密醒来提示、奶酪取走、天亮、投票提交、胜负揭示及按钮反馈。所有夜间公共音效必须固定时长和响度，不能编码醒来人数。私密音效应支持单独关闭，并由视觉或触觉反馈替代。

语音旁白可包含“所有人闭眼”“X 点到了”“天亮了”，但若精确报时会让玩家借声音回忆流程，这本身通常不破坏规则。是否向闭眼者播报每个数字需作为产品选择固定，不能因无人醒来跳号。

## 5 文案

关键文案至少包括：

- “你的骰点是 X，你会在 X 点醒来。”
- “夜晚禁止聊天、语音和表情。”
- “你醒来了。同一时刻还有：……”
- “奶酪还在桌上”与“奶酪已经不见了”。
- “你独自醒来并拿走了奶酪。”
- “已提交指认，结果将在所有人完成后公开。”

所有“官方规则”“平台变体”“房主设置”需有不同标签。避免用“绝对安全”“完全防作弊”等无法验证的描述。

## 6 市场与商店素材

若要上线游戏库，还需封面、横幅、玩法截图、短描述、长描述、人数/时长/年龄标签、内容分级说明和版权信息。商店截图不能展示尚未授权的原版组件，也不能把建议票制截图误导为原版官方流程。

## 7 交付格式建议

矢量图标保留 SVG 源文件，位图按 1x/2x/3x 输出，音频保留无损母带与平台压缩版。命名应包含对象、状态、主题和倍率，例如 `cheese_table_night_2x`。本命名仅为资产管理建议，不属于游戏规则。
