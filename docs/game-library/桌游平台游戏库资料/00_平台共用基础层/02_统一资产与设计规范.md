# 02 统一资产与设计规范

> 本文档基于《八款桌游规则与手机端卡牌化研究》研究报告的"统一资产清单"章节整理，定义平台所有游戏共用的资产规范与设计标准。

---

## 1. 品牌

### 1.1 应用图标

- 主图标：圆形或圆角矩形，辨识度优先，支持自适应图标（Android Adaptive Icon）。
- 尺寸规范：提供 48×48、72×72、96×96、144×144、192×192、512×512 等多尺寸导出。
- 格式：PNG（透明背景） + WebP（透明背景） + SVG（矢量母版）。
- 变体：深色主题图标、浅色主题图标、节日限定图标。

### 1.2 Logo

- 横版 Logo：用于启动页、商店图、页头。
- 竖版/方版 Logo：用于应用图标、社交分享卡片。
- 简化标志（Favicon / Mark）：用于小尺寸场景、通知栏、浏览器标签。
- 颜色变体：彩色版、单色版（白/黑）用于不同背景。
- 安全区：Logo 四周保留至少 10% 透明边距。

### 1.3 启动页

- 静态启动页：Logo + 品牌色背景 + 加载指示器。
- 启动页尺寸匹配常见手机分辨率（含刘海屏/挖孔屏适配）。
- 启动页文字/Logo 居中，避免关键区域被遮挡。

### 1.4 商店图

- 应用商店横图（Google Play：1024×500；App Store：不同尺寸要求）。
- 截图模板：每款游戏至少 4 张功能截图 + 1 张封面图。
- 截图标注：支持多语言文字覆盖，不嵌入不可翻译的图片文字。
- 宣传视频封面（可选）：16:9 静态图，用于商店视频预览。

### 1.5 模式封面

- 每款游戏模式有独立的封面图，用于大厅模式选择界面。
- 封面风格：统一品牌框架下区分各游戏视觉调性。
- 尺寸：16:9 横版（大厅卡片展示） + 3:4 竖版（列表展示）。
- 封面包含：游戏名称、人数范围、预估时长、难度标识。

## 2. 卡牌

### 2.1 卡牌正面模板

- 每张卡牌由以下分层组成（从底层到顶层）：
  1. 卡牌背景/主题边框（按游戏/规则集变化）。
  2. 插画/角色图像区域。
  3. 数值/标识（左上角或右上角）。
  4. 卡牌名称（顶部）。
  5. 能力/效果描述文字（底部或中部）。
  6. 能力图标（如有）。
  7. 状态覆盖层（如"已使用""已弃置""已淘汰"）。
- 模板采用矢量布局，文字和数值实时渲染，不烘焙进插画。

### 2.2 卡背

- 通用卡背：所有共用卡牌的统一卡背，含品牌 Logo 和装饰纹样。
- 游戏专属卡背：每款游戏可设计独立卡背，与主题风格一致。
- 特殊卡背：身份卡、角色卡、计分卡等特殊用途卡背。
- 卡背设计避免透光/可猜测性，确保完全遮盖正面信息。

### 2.3 边框

- 边框主题按规则集配置，支持：
  - 经典/复古边框（情书宫廷风）。
  - 现代/简约边框（Durian 水果主题）。
  - 黑暗/悬疑边框（囚徒之夜）。
  - 明亮/卡通边框（奶酪大盗、以鹅传鹅）。
- 边框包含颜色编码，用于快速区分卡牌类型（角色、行动、身份、计分等）。

### 2.4 数值牌

- 数值显示区域：统一位置（左上角或右上角）。
- 数值字体：大字号、高对比度，支持无障碍阅读。
- 数值范围指示：罗马数字、阿拉伯数字、符号或星级。
- 数值颜色编码：按稀有度或强度分级。

### 2.5 能力图标

- 通用能力图标集：查看、比较、交换、弃置、保护、猜测、替换等。
- 游戏专属能力图标：按游戏规则自定义。
- 图标风格：线条风格（Line Art） + 填充风格（Filled），支持双主题。
- 图标尺寸：卡牌内固定区域，确保可辨识性。

### 2.6 状态覆盖层

- 半透明覆盖层，叠加在卡牌之上表示当前状态：
  - 已选择（高亮边框）。
  - 已弃置（灰色覆盖 + 斜线）。
  - 已淘汰（红色覆盖 + X 标记）。
  - 已保护（蓝色护盾覆盖）。
  - 锁定中（锁图标）。
  - 可互动（发光边框提示）。
- 覆盖层使用统一的动画过渡效果。

## 3. 角色

### 3.1 头像

- 圆形裁切，用于玩家列表、计分板、聊天侧栏。
- 尺寸规格：小（32×32）、中（64×64）、大（128×128）。
- 格式：PNG 透明背景 + WebP 变体。
- 头像库：预置一组通用头像，同时支持玩家上传自定义头像（需审核）。

### 3.2 半身像

- 用于角色详情页、卡牌插画、胜利/失败展示。
- 比例：3:4 竖版，支持裁剪到卡牌正面区域。
- 分辨率：至少 512×682，保留 2× 素材。

### 3.3 剪影

- 用于身份隐藏阶段、未揭示角色的占位展示。
- 剪影风格：统一勾线 + 纯色填充，与角色实际形象轮廓一致。
- 不同角色剪影需有区分度，避免玩家混淆。

### 3.4 胜负表情

- 胜利表情：笑脸、欢呼、庆祝姿势。
- 失败表情：沮丧、惊讶、无奈。
- 表情动画：循环播放的轻量 Lottie 动画或序列帧。
- 表情尺寸：适配头像区域和全屏展示场景。

### 3.5 状态指示

- 淘汰状态：墓碑/幽灵/X 标记，灰暗色调。
- 保护状态：护盾/光环，蓝色或金色调。
- 断线状态：WiFi 断开/灰色头像，离线标记。
- 托管状态：机器人图标，自动标记。
- 房主标识：皇冠/星标。

## 4. 桌面

### 4.1 牌堆

- 牌堆视觉：卡牌堆叠效果，顶部显示卡背。
- 牌堆计数：剩余牌数数字指示。
- 牌堆交互：点击牌堆顶牌可视化翻牌动画。
- 多牌堆支持：主牌堆、弃牌堆、移除牌堆。

### 4.2 弃牌堆

- 弃牌堆视觉：已弃卡牌堆叠，顶部显示最新弃牌。
- 弃牌堆可点击展开查看历史弃牌（公共信息）。
- 弃牌顺序保持与游戏事件一致，不可重新排序。

### 4.3 票箱

- 用于投票环节的密封投票区域。
- 视觉：投票箱图标 + 已投票人数统计。
- 投票状态：未投票（灰色）、已投票（高亮）、已揭晓（公开结果）。
- 投票结果展示：柱状图或列表，匿名或公开（按规则集配置）。

### 4.4 计分轨

- 线性或环形计分轨道，展示当前轮次/整局得分。
- 计分轨分段显示：每段表示一个得分节点。
- 得分动画：棋子/标记沿轨道前进，配合音效。
- 多玩家计分轨并列展示，便于比较。

## 5. 动效

### 5.1 洗牌

- 卡牌从桌面飞起、旋转、交叉混合后落回。
- 时长：约 0.8~1.2 秒。
- 音效：扑克牌快速摩擦声。
- 服务端确认洗牌完成后客户端播放动效，动效期间屏蔽交互。

### 5.2 发牌

- 卡牌从牌堆依次飞向各玩家区域。
- 发牌顺序按游戏座位顺序。
- 每张牌发牌间隔约 0.15~0.25 秒。
- 发牌到私密区域时，卡牌翻转为正面（仅接收者可见正面）。
- 音效：轻快的纸牌放置声。

### 5.3 翻牌

- 卡牌从背面旋转 180° 到正面。
- 时长：约 0.3~0.5 秒。
- 缓动函数：ease-out。
- 翻牌完成后触发事件回调（如能力结算）。
- 音效：短促的翻牌声。

### 5.4 长按揭示

- 用于私密信息查看（如长按自己的手牌放大查看）。
- 长按 0.5 秒触发，松手恢复。
- 揭示区域：卡牌放大至屏幕中央或悬浮显示。
- 背景：半透明遮罩，防止他人偷窥。
- 防止截图：长按揭示期间启用防截屏 FLAG_SECURE。

### 5.5 投票

- 投票按钮/卡片从玩家区域飞入票箱。
- 投票时播放"提交成功"确认动画。
- 投票揭晓时，票箱打开，结果逐项展示。
- 动画：投票结果从票箱飞出，按顺序排列。
- 音效：投票时投递声，揭晓时鼓点/揭晓声。

### 5.6 同步揭晓

- 用于多人同时揭示场景（如 Yes/No 同时翻开、身份同时揭示）。
- 所有玩家在倒计时结束后同时揭晓。
- 揭晓动画：卡牌/标记同时翻转，产生"揭晓墙"效果。
- 倒计时：3-2-1 数字动画 + 音效。

## 6. 音频

### 6.1 大厅 BGM

- 循环播放的背景音乐，营造平台氛围。
- 每款游戏模式有专属 BGM 或主题变奏。
- BGM 音量可调，支持与语音频道混音。
- 格式：OGG/MP3，压缩比特率 ≥ 128kbps。

### 6.2 牌桌氛围

- 游戏过程中的环境音（如林间虫鸣、夜间风声、室内环境声）。
- 氛围音与游戏状态联动（如夜间阶段安静，白天阶段活跃）。
- 音量低于 BGM 和 UI 音效，作为背景层。

### 6.3 UI 音效

- 按钮点击、页面切换、弹窗打开/关闭的短促反馈音。
- 统一音效风格，确保全平台一致。
- 关键操作有明确的声音反馈（如确认、取消、警告）。

### 6.4 倒计时

- 回合倒计时：每秒滴答声，最后 5 秒加速或变调。
- 抢答倒计时：急促的倒计时音效，结束时响铃。
- 同步揭晓倒计时：3-2-1 数字播报或音效。

### 6.5 语音频道

- 游戏内实时语音，基于 WebRTC。
- 语音频道按游戏阶段自动切换（如全体讨论、私密沟通、观战隔离）。
- 语音质量：Opus 编码，16kHz 采样率，自适应码率。
- 语音控制：一键静音、音量调节、语音反馈指示器。
- 语音转文字（可选）：为无障碍和举报提供字幕。

### 6.6 胜负短乐句

- 胜利/失败时播放的短乐句（约 2~4 秒）。
- 每款游戏有专属的胜负乐句。
- 乐句风格与游戏主题一致（如宫廷号角、节庆欢呼、悬疑落幕）。
- 胜负乐句与 BGM 平滑过渡。

## 7. 网络

### 7.1 延迟指示

- 实时显示当前网络延迟（RTT），单位 ms。
- 延迟指示器：颜色编码（绿 < 100ms、黄 100~300ms、红 > 300ms）。
- 延迟指示位置：游戏界面角落，不遮挡主要内容。

### 7.2 弱网模式

- 检测到弱网（RTT > 300ms 或丢包率 > 5%）时自动切换。
- 弱网策略：
  - 降低动画质量（关闭非必要动画）。
  - 增加操作超时时间（客户端缓冲）。
  - 降低语音质量（自适应码率下调）。
  - 减少非关键网络请求（如排行榜刷新）。
- 弱网提示：非侵入式 Toast 提示"网络状态不佳"。

### 7.3 掉线检测

- 客户端心跳：每 5 秒发送一次心跳包。
- 服务器检测：连续 3 次心跳未收到判定为断线。
- 客户端检测：WebSocket 连接断开或 15 秒无响应判定为断线。
- 断线提示：全屏遮罩 + 断线状态图标 + 重连进度。

### 7.4 重连

- 自动重连：断线后自动尝试重连，最多 5 次。
- 重连间隔：1s、2s、4s、8s、16s（指数退避）。
- 重连成功：恢复对局状态，同步断线期间事件。
- 重连失败：提示玩家手动重连或返回大厅。

### 7.5 托管

- 断线超时（默认 30 秒）后自动托管。
- 托管行为参数化，按规则集配置。
- 托管期间其他玩家可见"XXX 已托管"提示。
- 玩家重连后自动退出托管。

### 7.6 房主迁移

- 房主断线超时 60 秒后触发迁移。
- 迁移目标：对局中存活时间最长的玩家。
- 迁移过程：服务端原子操作，无感迁移。
- 新房主获得全部房主权限。

### 7.7 维护状态

- 服务器维护前广播通知，提前 5 分钟/1 分钟/30 秒三次提醒。
- 维护期间禁止新对局创建。
- 进行中的对局允许完成当前轮次后强制结束。
- 维护页面：品牌 Logo + 维护说明 + 预计完成时间。

## 8. 治理

### 8.1 举报

- 举报入口：玩家头像菜单、聊天消息长按、对局结束后反馈。
- 举报类型：言语骚扰、恶意捣乱、作弊、身份冒充、不当内容。
- 举报信息：举报人 ID、被举报人 ID、对局 ID、事件时间戳、截图/日志。
- 举报处理：自动审核（关键词匹配）+ 人工复核。
- 举报反馈：处理完成后通知举报人。

### 8.2 拉黑

- 拉黑后不再匹配到该玩家，不接收其消息。
- 拉黑列表管理：查看、解除、同步。
- 拉黑上限：默认 100 人。

### 8.3 静音

- 静音单个玩家（语音 + 文字）。
- 静音时限：本局、本日、永久。
- 静音操作不影响对局进行。

### 8.4 快捷语

- 预设快捷语列表，用于无法/不愿语音的场景。
- 快捷语分类：问候、回应、催促、表达情绪。
- 快捷语可自定义编辑（本地保存）。
- 快捷语在 UI 上以气泡/按钮形式展示。

### 8.5 敏感题库

- 伪人测试等涉及题库的游戏，题库需进行敏感内容过滤。
- 敏感词库定期更新，来源包括自定义词库和第三方服务。
- 出题时实时过滤，拦截含敏感词的问题。
- 敏感题库记录审核日志。

### 8.6 未成年人模式

- 未满 18 岁用户自动进入未成年人模式。
- 限制：每日游戏时长、消费限额、语音限制、社交限制。
- 未成年人不可访问含敏感内容的游戏模式。
- 未成年人模式下语音聊天默认关闭，仅文字聊天。
- 家长监控：家长可查看孩子游戏记录和时长。

## 9. 无障碍

### 9.1 高对比主题

- 提供高对比度颜色主题，满足 WCAG 2.1 AA 标准（对比度 ≥ 4.5:1）。
- 高对比主题下所有文字、图标、UI 元素保持可辨识。
- 不依赖颜色传递关键信息（辅以符号和文字）。

### 9.2 色盲纹理

- 卡牌和 UI 元素除颜色外，辅以纹理/图案区分。
- 支持三种常见色盲模式：红色盲、绿色盲、蓝黄色盲。
- 色盲模式下的颜色映射：保留色相差异或使用纹理替代。

### 9.3 大字号

- 支持系统字体缩放，UI 布局自适应。
- 大字号模式下文字不截断、不重叠。
- 关键信息（数值、名称、倒计时）字号不低于 16sp。

### 9.4 低动态

- 提供减少动画模式，关闭非必要动效。
- 保留必要反馈（如操作成功/失败提示）。
- 低动态模式下，动效替换为静态指示器。

### 9.5 字幕与触觉替代

- 语音内容提供实时字幕（语音转文字）。
- 音效提示提供视觉替代（如闪烁、图标变化）。
- 关键事件提供触觉反馈（振动模式），支持自定义振动强度。

## 10. 本地化

### 10.1 语言支持

- 初始支持：简体中文、繁体中文（香港/台湾）、英文。
- 未来扩展：日文、韩文、泰文、西班牙文、法文等。
- 所有 UI 文案使用文本键（`string_key`），不硬编码。

### 10.2 文本键规范

- 命名格式：`module.component.element.state`（如 `lobby.button.start_game`）。
- 文本键包含上下文注释，方便翻译人员理解。
- 文本键管理系统：支持在线编辑和 OTA 更新。

### 10.3 动态字号

- 不同语言文本长度差异大，UI 布局需动态适应。
- 按钮、标签、弹窗等控件支持文字长度自适应。
- 长文本使用省略号截断 + 全文本 Tooltip。

### 10.4 长文本安全区

- 卡牌描述、规则说明等区域预留长文本空间。
- 安全区：至少容纳英文文本 2 倍于中文长度的扩展空间。
- 长文本区域支持滚动查看。

### 10.5 语音字幕

- 语音频道内容实时转写为字幕。
- 字幕语言跟随系统语言设置。
- 字幕显示位置：游戏界面底部或侧边。
- 字幕历史可滚动查看。

## 11. 数据

### 11.1 规则版本

- 规则版本记录：`rulesetId`、`version`（semver）、`changelog`、`releaseDate`。
- 版本号格式：主版本.次版本.修订号（如 1.2.0）。
- 主版本升级：规则不兼容变更（如牌表修改）。
- 次版本升级：规则兼容性变更（如参数调整）。
- 修订号升级：错误修复、文案更新。

### 11.2 卡牌 ID

- 卡牌 ID 格式：`{rulesetId}_{cardType}_{number}`（如 `love_letter_guard_01`）。
- ID 全局唯一，不可变更，用于数据关联和日志记录。
- 废弃卡牌的 ID 保留但标记为 `deprecated`，不重复使用。

### 11.3 版权方

- 每张卡牌/角色/素材记录版权方信息。
- 版权字段：`copyrightOwner`、`licenseType`、`licenseExpiry`、`territory`。
- 版权到期前自动提醒续期。
- 版权信息在数据管理后台可编辑。

### 11.4 卡包

- 卡包定义：一组卡牌的集合，按主题/扩展包/赛季组织。
- 卡包元数据：`packId`、`name`、`description`、`cards`、`price`、`releaseDate`。
- 卡包与规则集关联：规则集引用卡包中的卡牌。

### 11.5 敏感标签

- 每张卡牌/题库/内容可标记敏感标签：`violent`、`sexual`、`gambling`、`drug`、`horror`。
- 敏感标签影响内容分发（未成年人模式、地区合规）。
- 标签系统支持多级分类和自定义标签。

### 11.6 下架状态

- 素材下架状态：`active`、`deprecated`、`removed`、`replaced`。
- 下架素材在游戏中不可用，但历史对局记录保留。
- 下架操作需记录操作人、时间、原因。

## 12. 法律

### 12.1 用户协议

- 用户注册时需同意用户协议。
- 协议内容：服务条款、用户行为规范、账号管理、免责声明。
- 协议更新需重新获取用户同意。
- 协议版本号记录，与用户绑定。

### 12.2 隐私政策

- 收集的数据类型、用途、存储期限、共享范围。
- 用户数据删除/导出权利说明。
- 未成年人隐私保护说明。
- 隐私政策链接在应用内多处可访问（注册页、设置页、游戏内）。

### 12.3 语音提示

- 语音聊天功能首次使用时提示："语音内容将被记录，用于举报审核"。
- 语音提示在应用内至少展示一次。
- 语音数据处理说明：仅用于举报核查，不用于其他目的。

### 12.4 年龄分级

- 应用商店年龄分级：按目标市场要求（如 ESRB、PEGI、IARC）。
- 应用内年龄验证：用户注册时填写出生日期。
- 年龄分级影响内容可见性（如含赌场元素的游戏模式需年龄限制）。

### 12.5 授权证明归档

- 每款游戏的数字改编授权文件归档管理。
- 授权记录：授权方、授权范围、授权期限、授权费用。
- 授权到期前 90 天自动提醒。
- 授权文件格式：PDF 扫描件 + 元数据记录。
