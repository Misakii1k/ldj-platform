# 00 平台共用基础层

> 平台定位：手机端实时卡牌桌游平台的共用基础架构与设计规范。

---

## 平台定位

本平台是一个面向手机端的**实时多人卡牌桌游平台**，支持多款桌游在同一技术架构上运行。平台的核心设计理念是：

- **共用架构**：所有游戏共享同一套技术底座，包括房间管理、规则集引擎、回合状态机、事件系统和网络层。
- **权威服务器**：所有随机性、判定和胜负逻辑在服务器执行，客户端只提交意图，确保公平性。
- **分级可见性**：每个事件声明接收范围，精确控制信息分发，保障游戏私密性和安全性。
- **版本化规则**：每局游戏锁定规则集版本，支持多版本并行运行和旧局回放。

## 建议产品路线

| 阶段 | 内容 | 核心系统 |
|------|------|---------|
| MVP 1 | 情书（现代版 + 经典版） | 房间管理、规则集引擎、回合状态机、事件系统、断线重连 |
| MVP 2 | Durian | 私密视图引擎、抢答/按铃机制、反向信息分发 |
| MVP 3 | 伪人测试 | 语音频道、举报系统、内容审核、敏感词过滤 |
| MVP 4 | 奶酪大盗 / 以鹅传鹅 | 复杂私密频道、视频或主持流程 |
| 暂缓 | Ding、囚徒之夜 | 待官方规则补齐 |
