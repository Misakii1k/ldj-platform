# 04 资产需求

## 1 授权边界

Oink Games 官方版具有鲜明包装、美术和组件设计。若项目未获得授权，不得直接使用官方卡面、猩猩角色、订单板版式、标识、商品照片或说明书插图。可制作原创的“丛林水果店”视觉，但需法务评估名称与整体近似风险。

## 2 组件资产

| 类别 | 数量或状态 | 要求 |
|---|---:|---|
| 水果卡 | 对应 28 张官方牌的数据组合 | 正面、背面、卡架展示、检查放大 |
| 猩猩卡 | 3 张 | 独立角色、效果图标、文字版效果 |
| 订单板 | 1 套 | 各水果轨道、数值标记、移动端布局 |
| 卡架 | 7 份 | 自己背面、他人正面、空置状态 |
| 愤怒标记 | 7 份 | 玩家颜色区分，不能只靠颜色 |
| 手铃 | 1 个 | 静止、按下、震动、禁用 |
| 店长怒气 | 1–7 | 数字、表情或姿态、无障碍文本 |

水果种类、每张卡的图标数量和订单牌组合必须从合法规则/组件清单录入，不凭印象补齐。

## 3 场景与角色

需要丛林水果店桌面、仓库或货架背景、店长办公室入口、检查聚光区域。店长至少包含平静、被呼叫、检查、斥责和怒气升级状态。3 名猩猩兄弟姐妹各自需要静态牌面和触发动效。

## 4 动效

- 发库存卡：正面只朝向其他玩家，自己的视角永不翻正。
- 抽订单：卡牌进入中央并展开二选一。
- 更新订单：水果标记沿轨道增加。
- 按铃：铃锤下压、铃体震动、店长冲出。
- 检查：库存逐张翻开，数字汇总，超卖差额高亮。
- 处罚：个人标记移动，再展示怒气升级。

所有动效提供减少动态版本，检查结果不能仅靠动画表达。

## 5 音频

需要手铃主音效、店长脚步、低声咆哮、处罚、怒气升级、卡牌翻面、订单标记移动、回合提示和胜负音乐。手铃是核心辨识资产，应清晰但避免过高峰值；提供音量单独调节和视觉替代。

## 6 文案

关键界面文案包括：“你不能查看自己的库存”“选择本单接受的水果”“订单等于库存仍然安全”“你正在质疑上一位员工”“按铃错误，惩罚由你承担”“店长当前怒气为 X”。

猩猩卡效果需有完整版和桌面短版，两者语义一致。多语言版本要保留图标映射，不因文字变长遮挡订单数。

## 7 商店素材

需要游戏封面、库图标、横幅、2–4 张真实界面截图、玩法短片、2–7 人/20 分钟/7+ 标签、版权与设计者署名。若获官方授权，署名应与 Oink Games 官方信息一致；未授权时不能使用官方产品照制造合作印象。
