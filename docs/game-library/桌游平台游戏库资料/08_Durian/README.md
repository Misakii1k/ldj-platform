# Durian

## 文档定位

本目录整理 Oink Games《Durian》的中文规则与线上化资料。游戏以丛林水果店为背景：员工看得见别人的库存卡，却看不见自己的卡；大家不断接受二选一订单，并在怀疑订单超过库存时按铃叫来猩猩店长。判断错误的一方承受店长当前怒气值。

## 资料标签

- **官方**：Oink Games 官方商品页或正式规则支持。
- **变体**：非标准玩法、社群玩法或平台可选配置。
- **建议**：数字平台为可用性、防作弊和节奏提出的方案。
- **待确认**：需要对照目标语言版规则书逐条锁定。

## 官方概览

| 项目 | 内容 |
|---|---|
| 设计 | Masato Uesugi |
| 美术 | Hiroko Izumida |
| 发行 | Oink Games，2020 |
| 人数 | 2–7 人 |
| 时长 | 约 20 分钟 |
| 年龄 | 7 岁以上 |
| 核心机制 | 看别人不看自己、共享订单、风险判断、按铃质疑 |
| 结束触发 | 某玩家承受怒气后达到或越过淘汰阈值；阈值细节需按规则书确认 |

## 官方组件

28 张水果卡、3 张猩猩兄弟姐妹卡、1 块订单板、7 个卡架、7 枚愤怒店长标记、1 个手铃及说明书。不同地区版本的说明书语言组合不同。

## 线上化边界

核心信息结构不可改变：本人不能查看自己架上的库存卡；其他玩家的卡公开可见；存在一张未知库存；订单逐步累积；任何轮到行动的玩家都面临“继续下单或按铃”的判断。系统可以自动计算争议结果，但必须在按铃前隐藏精确库存总量，不能用提示替玩家判断。
