# 情书：数据与状态

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为“待确认”，不得静默当作正式规则实现。

## 证据层级

- **A（官方/一手）**：出版方规则书、开发者商店页、官方更新公告；可作为实现基线。
- **B（可靠二手）**：有完整演示、可与 A 级互证的专业资料；用于补充解释。
- **C（线索）**：零售页、媒体短文、玩家视频/社区讨论；只能提示方向，不能单独决定规则。
- **D（设计建议）**：本文为数字平台提出的实现方案，不声称是原版规则。

## 静态数据
- `Ruleset`：`classic_16_zman_A5104`、人数 2–4、阈值表、来源。
- `CardDefinition`：角色 ID、数值、数量、目标、强制条件、效果、公开说明。
- 译名可变化，但稳定 ID 与数值不变。

## 对局状态
- 整局：玩家、好感、轮次、先手、规则版本。
- 当前轮：牌库、面朝下移除牌、两人局公开移除牌、手牌、弃牌、存活/保护。
- 回合：当前玩家、已摸牌、可打牌、目标、守卫猜测、结算阶段。

## 状态机
`ROUND_SETUP → DEAL → TURN_DRAW → CHOOSE_DISCARD → CHOOSE_TARGET/CHOICE → RESOLVE → ELIMINATION_CHECK → DECK_CHECK → NEXT_TURN/ROUND_SHOWDOWN → TOKEN_AWARD → MATCH_CHECK → NEXT_ROUND/MATCH_END`

## 不变量
- 存活玩家回合外 1 张；摸牌后 2 张。
- 弃牌永久公开且顺序固定；淘汰时手牌公开弃置。
- 侍女保护在该玩家下回合开始解除。
- 伯爵夫人强制规则限制可打牌集合。
- 王子在空牌库时取面朝下移除牌；两人局公开移除牌不用于补牌。

牧师查看、国王交换、男爵比较只发最少私密信息；公开日志不泄漏牌值。
