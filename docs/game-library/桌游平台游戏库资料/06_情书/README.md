# 情书（Love Letter）：资料总览

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为“待确认”，不得静默当作正式规则实现。

## 版本基线
选定 **Z-Man Games 经典 16 张角色牌版（产品代码 A5104）**：2–4 人、约 20 分钟、10+，设计师 Seiji Kanai；官方产品页列 16 张角色牌、4 张参考牌、13 枚好感标记。与支持 2–6 人、含 Spy/Chancellor 的 2019/新版分开管理，绝不混牌。

## 证据层级

- **A（官方/一手）**：出版方规则书、开发者商店页、官方更新公告；可作为实现基线。
- **B（可靠二手）**：有完整演示、可与 A 级互证的专业资料；用于补充解释。
- **C（线索）**：零售页、媒体短文、玩家视频/社区讨论；只能提示方向，不能单独决定规则。
- **D（设计建议）**：本文为数字平台提出的实现方案，不声称是原版规则。

## 核心体验
每轮每人通常持 1 张牌：摸 1、打 1 并执行效果。通过推理和逼迫弃牌成为最后存活者；牌库耗尽则手牌数值最高者获胜。累计好感标记达人数阈值后赢得整局。
