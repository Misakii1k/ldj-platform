# 情书：争议与待确认

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为“待确认”，不得静默当作正式规则实现。

## 证据层级

- **A（官方/一手）**：出版方规则书、开发者商店页、官方更新公告；可作为实现基线。
- **B（可靠二手）**：有完整演示、可与 A 级互证的专业资料；用于补充解释。
- **C（线索）**：零售页、媒体短文、玩家视频/社区讨论；只能提示方向，不能单独决定规则。
- **D（设计建议）**：本文为数字平台提出的实现方案，不声称是原版规则。

## 最大争议：版本混用
- Z-Man 产品页列 **16 角色牌、4 参考牌、13 标记、2–4 人**，为经典基线。
- 2019/新版常见为 **21 张角色牌、2–6 人**，加入 Spy 和 Chancellor，旧角色数量也可能变化。
- 主题版可能改名、改效果或加特殊规则，不能按“情书”名称合并。

## 待核验
1. 目标中文实体版的牌面数值与译名。
2. 轮末同值且弃牌总和仍同分时如何发标记。
3. 王子在牌库空时使用移除牌及后续耗尽判定。
4. 中文版是否保留“最近约会者先手”，随机先手是否作为房规。
5. 伯爵夫人是与王子/国王同手时必须打出，不是立即公开。

## 测试案例
- 他人全受保护时打守卫：无目标、效果落空。
- 伯爵夫人+王子：只能打伯爵夫人；伯爵夫人+公主：均可选。
- 王子迫使公主弃牌：立即淘汰，不补牌。
- 男爵同值：无人淘汰。
- 牌库空多人存活：先比手牌，再按目标版处理弃牌总和与平局。
