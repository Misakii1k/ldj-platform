# 情书：界面与交互

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为“待确认”，不得静默当作正式规则实现。

## 证据层级

- **A（官方/一手）**：出版方规则书、开发者商店页、官方更新公告；可作为实现基线。
- **B（可靠二手）**：有完整演示、可与 A 级互证的专业资料；用于补充解释。
- **C（线索）**：零售页、媒体短文、玩家视频/社区讨论；只能提示方向，不能单独决定规则。
- **D（设计建议）**：本文为数字平台提出的实现方案，不声称是原版规则。

## 布局
- 中央：牌库剩余、回合、先手与规则版本。
- 玩家区：头像、好感、公开弃牌、淘汰、侍女保护。
- 本人区：手牌；伯爵夫人强制时禁用其他牌并解释。

## 流程
1. 摸牌后选牌；长按看大图，误触不直接打出。
2. 选牌后显示合法目标；受保护者不可点。
3. 守卫弹角色列表且禁猜守卫；提交前汇总目标+猜测。
4. 牧师结果仅私密遮罩显示。
5. 男爵公共区只播淘汰者/平手，不展示双方牌。
6. 国王交换不向旁观者展示牌面。
7. 王子指向自己二次确认；弃公主立即淘汰。

## 边界
- 所有他人受保护时，守卫/牧师/男爵/国王允许弃牌并显示效果落空。
- 王子可选自己，通常仍有合法目标。
- 淘汰者不能操作，未完成私密弹窗关闭。
- 轮末按数值、弃牌总和依次展示，平局文字常驻。

角色同时显示数值、名称和图标；支持大字、屏幕阅读、减少动画及键盘/手柄。
