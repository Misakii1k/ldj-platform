# 囚徒之夜：争议与待确认

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为“待确认”，不得静默当作正式规则实现。

## 证据层级

- **A（官方/一手）**：出版方规则书、开发者商店页、官方更新公告；可作为实现基线。
- **B（可靠二手）**：有完整演示、可与 A 级互证的专业资料；用于补充解释。
- **C（线索）**：零售页、媒体短文、玩家视频/社区讨论；只能提示方向，不能单独决定规则。
- **D（设计建议）**：本文为数字平台提出的实现方案，不声称是原版规则。

## P0：阻塞实现
1. 正式中文名、原文名、设计师、出版方、授权方、版次？
2. 完整组件；4/5/6 人配置是否不同？
3. 所有身份/卡牌原文、时机、目标与优先级。
4. 一轮/一局准确结构、起手与方向。
5. 胜利、淘汰、平票、耗尽、无目标、同时胜利处理。

## P1：影响体验
- 是否允许自由讨论、插话、私聊、亮牌？
- 决策公开还是秘密，能否撤回，何时揭示？
- 淘汰者能否观看/发言；是否有主持人？
- 官方时长、年龄、敏感内容和人数上限？

## 取证验收
- 同一盒装版：封面、盒底、条码、版权页、组件全家福、规则书连续照片。
- 两人独立录入数量与效果再核差异。
- 每条保存“页码—原文—解释—测试案例”。
- 不同印次冲突则分建版本，不用玩家习惯覆盖印刷规则。

商品页只能证明市场流通和宣传标签，视频标题只能证明存在相关讨论；均不足以确认细则。
