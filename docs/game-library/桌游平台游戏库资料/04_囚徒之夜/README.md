# 囚徒之夜：资料总览

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为“待确认”，不得静默当作正式规则实现。

## 版本基线
当前对象是中国大陆市场流通、常被描述为“4–6 人、身份推理、嘴炮博弈”的实体卡牌《囚徒之夜》。截至 2026-08-01，未找到公开可访问的出版方规则书、设计师页面或稳定官方产品页；故采用 **“中文流通版待验”** 作为版本名，不臆造角色、牌数和流程。

## 证据层级

- **A（官方/一手）**：出版方规则书、开发者商店页、官方更新公告；可作为实现基线。
- **B（可靠二手）**：有完整演示、可与 A 级互证的专业资料；用于补充解释。
- **C（线索）**：零售页、媒体短文、玩家视频/社区讨论；只能提示方向，不能单独决定规则。
- **D（设计建议）**：本文为数字平台提出的实现方案，不声称是原版规则。

## 已确认与未确认
- **[B/C，多源一致]**：轻量身份推理、聚会交流取向；常见资料给出 4–6 人。
- **[C]**：市场存在“恶魔白”“游人码头”等销售描述，但无法据此判断出版授权、版次或组件差异。
- **[未确认]**：组件表、身份名称与数量、发言顺序、行动效果、淘汰/计分、平局规则。
