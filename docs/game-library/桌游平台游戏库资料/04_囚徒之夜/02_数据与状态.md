# 囚徒之夜：数据与状态

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为“待确认”，不得静默当作正式规则实现。

## 证据层级

- **A（官方/一手）**：出版方规则书、开发者商店页、官方更新公告；可作为实现基线。
- **B（可靠二手）**：有完整演示、可与 A 级互证的专业资料；用于补充解释。
- **C（线索）**：零售页、媒体短文、玩家视频/社区讨论；只能提示方向，不能单独决定规则。
- **D（设计建议）**：本文为数字平台提出的实现方案，不声称是原版规则。

## 版本化对象（D 级）
- **GameDefinition**：游戏 ID、规则版本、语言、人数、来源快照、草案/已核验/停用。
- **RoleDefinition**：稳定 ID、名称、阵营（若确有）、公开/私密说明、人数配置、胜利条件引用。
- **CardDefinition**：牌类、数量、可见性、合法目标、触发窗口、效果序列、来源页码。
- **RoomRule**：人数、限时、语音、断线策略、房规；房规与官方规则分栏。
- **PlayerState**：座位、在线、私密身份/手牌、可用行动、存活、托管。
- **RoundState**：轮次、阶段、行动者、公共区、秘密提交、待结算队列。
- **AuditEvent**：服务器序号、时间、操作者、动作、公开载荷、加密私密载荷、规则版本。

## 状态机
`LOBBY → READY_CHECK → SECRET_SETUP → INFORMATION → DISCUSSION → COMMIT → REVEAL → RESOLVE → WIN_CHECK → NEXT_ROUND / GAME_OVER`

每一跳需定义进入条件、允许动作、超时动作和退出条件。未取得规则书前，中段细分只作占位。

## 可见性与恢复
- 公共：座位、计时、阶段、已公开事件和规则允许的投票结果。
- 私有：本人身份、手牌、秘密行动及本人结果。
- 服务端：牌序、身份、随机种子承诺、结算队列。
- 服务器权威；随机结果写入不可变日志，重连按日志重建。
- 超时、离线、重复提交须幂等；自动选择醒目标注。
- 规则版本随对局固化，更新不改变进行中的对局。
