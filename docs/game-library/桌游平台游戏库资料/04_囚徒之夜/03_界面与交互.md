# 囚徒之夜：界面与交互

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为“待确认”，不得静默当作正式规则实现。

## 证据层级

- **A（官方/一手）**：出版方规则书、开发者商店页、官方更新公告；可作为实现基线。
- **B（可靠二手）**：有完整演示、可与 A 级互证的专业资料；用于补充解释。
- **C（线索）**：零售页、媒体短文、玩家视频/社区讨论；只能提示方向，不能单独决定规则。
- **D（设计建议）**：本文为数字平台提出的实现方案，不声称是原版规则。

## 核心页面
1. **游戏详情**：显示“中文流通版待验”、4–6 人、证据状态及缺口警告。
2. **房间**：座位、准备、语音、版本与房规；房规逐项确认。
3. **秘密信息**：身份/手牌长按查看或隐私遮罩；切后台立即遮盖。
4. **讨论桌面**：当前发言者、剩余时间、申请发言与静音；不把转写当事实。
5. **决策面板**：合法目标高亮，不可撤销操作二次确认。
6. **揭示结算**：动画可跳过，文字日志常驻，写明规则原因。
7. **终局**：胜者、身份揭示范围、关键事件与版本；提供举报。

## 原则与异常
- 私密信息不进入公共通知或屏幕预览。
- 弱网显示服务器确认状态；不以颜色单独表达阵营。
- 提供静音、屏蔽、举报、踢人记录和敏感词设置。
- 断线保留座位并倒计时；恢复只补发有权信息。
- 未确认规则前不得自动随机投票。
- 房主不能改后台结果，只能终止或开启明确标记的房规重赛。
