# 囚徒之夜：游戏规则（待实物核验基线）

> 文档定位：产品与规则资料，不含代码。凡未被高等级来源确认的细节均标为“待确认”，不得静默当作正式规则实现。

## 重要结论
公开资料不足以可靠复原正式规则。下文的抽象骨架是 **D 级产品建模**，不是原版规则转录。

## 证据层级

- **A（官方/一手）**：出版方规则书、开发者商店页、官方更新公告；可作为实现基线。
- **B（可靠二手）**：有完整演示、可与 A 级互证的专业资料；用于补充解释。
- **C（线索）**：零售页、媒体短文、玩家视频/社区讨论；只能提示方向，不能单独决定规则。
- **D（设计建议）**：本文为数字平台提出的实现方案，不声称是原版规则。

## 已证实事实
- 面向 4–6 人的轻推理聚会卡牌（B/C）。
- 核心体验被描述为身份推理、口头辩论/欺骗与逻辑判断（B/C）。
- 视频标题“全员恶人”“好人如何把自己说成坏蛋”提示身份表象与真实立场可能有反差，但不能推导具体能力（C）。

## 数字原型抽象回合
1. **建房与入座**：校验人数、版本和房规；房主无规则优势。
2. **秘密分发**：服务器私下分配身份/手牌，客户端只见本人信息。
3. **信息阶段**：展示规则允许的公共事件或目标。
4. **陈述阶段**：依次陈述、质询；系统记录计时与顺序，不判断真假。
5. **决策阶段**：秘密或公开提交行动/投票；能否修改须由规则书确认。
6. **揭示与结算**：按确定优先级揭示并处理效果。
7. **终局检查**：检查阵营/个人胜利、淘汰或轮数条件。
