# 04_资产需求.md — 资产清单与权利前置说明

## 证据层级说明

| 层级 | 标签 | 定义 |
|------|------|------|
| A | 官方/一手 | 官方说明书、出版社公告、设计师声明、实测截图/录像 |
| B | 可靠二手 | 权威开箱/评测、授权渠道商品详情、官方客服回复 |
| C | 线索 | 非官方讨论、第三方商品页、二手交易描述、用户评论 |
| D | 设计建议 | 基于同类游戏通用机制的设计推测，无直接证据 |

## 权利前置说明

> **重要：Ding 游戏由一刻馆出版发行。任何数字版本实现均需获得一刻馆的正式授权。本资产清单仅用于研发参考，不构成对任何素材的使用授权。**

| 权利类型 | 说明 | 状态 |
|----------|------|------|
| 游戏名称使用权 | "Ding" 和 "眼疾脑快" 名称的使用 | 需获得一刻馆授权 |
| 卡牌美术版权 | 原版卡牌图案、设计的复制/改编权 | 需获得一刻馆授权 |
| 规则机制版权 | 游戏规则机制的实现许可 | 需获得一刻馆授权 |
| 商标权 | 一刻馆品牌标识的使用 | 需获得一刻馆授权 |

## 资产规格建议（D 级）

| 资产类型 | 建议规格 | 说明 |
|----------|----------|------|
| 卡牌图案 | SVG 或 512x512px+ PNG | 矢量优先，确保缩放清晰 |
| UI 图标 | 24-48px SVG/PNG | 适配不同分辨率 |
| 背景图 | 1920x1080px 或适配比例 | 适配常见屏幕尺寸 |
| 音效 | MP3 或 OGG, <500KB/个 | 短音效，快速加载 |
| 背景音乐 | MP3 或 OGG, <5MB | 循环播放，可淡入淡出 |
