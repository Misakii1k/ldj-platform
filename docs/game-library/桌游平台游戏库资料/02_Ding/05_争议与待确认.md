## 三、研发建议

### 短期（当前阶段）

1. 基于通用抢答引擎框架搭建基础架构
2. 所有规则参数化，便于后续调整
3. 保持铃铛/无铃铛两种模式的兼容性
4. 不做任何绑定到具体规则/图案/颜色的实现

### 中期（获取 A 级来源后）

1. 根据官方说明书补充规则细节
2. 根据官方牌表实现卡牌逻辑
3. 根据官方美术设计或授权重新设计 UI

### 长期（上线前）

1. 获得一刻馆的正式授权
2. 完成所有规则细节的验证和确认
3. 进行充分的玩家测试，确保规则实现的准确性

## 四、争议解决流程

当发现新的争议或待确认项时，请按以下流程处理：

1. 将新争议记录到本文档
2. 标注证据层级（A/B/C/D）
3. 评估优先级（高/中/低）
4. 如可能，提供解决方案或获取途径
5. 在获得更高等级来源后更新本文档
