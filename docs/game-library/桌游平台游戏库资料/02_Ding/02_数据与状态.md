# 02_数据与状态.md — 数据模型与状态机设计

## 证据层级说明

| 层级 | 标签 | 定义 |
|------|------|------|
| A | 官方/一手 | 官方说明书、出版社公告、设计师声明、实测截图/录像 |
| B | 可靠二手 | 权威开箱/评测、授权渠道商品详情、官方客服回复 |
| C | 线索 | 非官方讨论、第三方商品页、二手交易描述、用户评论 |
| D | 设计建议 | 基于同类游戏通用机制的设计推测，无直接证据 |

> **注意：以下所有数据模型和状态机设计均基于 D 级（设计建议），无官方依据。在获得 A 级来源前，所有字段名称和结构均可修改。**

## 核心数据模型（D 级 — 设计建议）

### 卡牌 Card

| 字段 | 类型 | 说明 | 证据层级 |
|------|------|------|----------|
| card_id | string | 唯一标识符 | D |
| type | enum | 卡牌类型（待确认） | D |
| pattern | string | 图案描述（待确认） | D |
| color | string | 颜色属性（待确认） | D |
| special_effect | string | 特殊效果（待确认，可能不存在） | D |

### 玩家 Player

| 字段 | 类型 | 说明 | 证据层级 |
|------|------|------|----------|
| player_id | string | 玩家唯一标识 | D |
| nickname | string | 昵称 | D |
| score | integer | 当前得分 | D |
| status | enum | 玩家状态（见下方状态机） | D |
| penalty_count | integer | 错误次数（待确认） | D |

### 回合 Round

| 字段 | 类型 | 说明 | 证据层级 |
|------|------|------|----------|
| round_id | string | 回合唯一标识 | D |
| round_number | integer | 回合序号 | D |
| cards_displayed | string[] | 本轮展示的卡牌 ID 列表 | D |
| start_time | timestamp | 回合开始时间 | D |
| response_window | duration | 反应窗口时长（待确认） | D |
| status | enum | 回合状态（见下方状态机） | D |

### 游戏 Game

| 字段 | 类型 | 说明 | 证据层级 |
|------|------|------|----------|
| game_id | string | 游戏唯一标识 | D |
| players | Player[] | 参与玩家列表 | D |
| current_round | integer | 当前回合数 | D |
| total_rounds | integer | 总回合数（待确认） | D |
| status | enum | 游戏状态（见下方状态机） | D |
| winner_id | string | 获胜者 ID（游戏结束时） | D |
| rules_version | string | 规则版本标识 | D |
| bell_enabled | boolean | 是否启用铃铛模式（待确认） | D |

## 状态机设计（D 级 — 设计建议）

### 游戏级状态机 GameState

```
┌───────────┐     ┌──────────────┐     ┌──────────────┐     ┌───────────┐
│  LOBBY    │────>│  PLAYING     │────>│  ROUND_END   │────>│  FINISHED │
│  等待中   │     │  游戏中      │     │  回合结算    │     │  已结束   │
└───────────┘     └──────────────┘     └──────────────┘     └───────────┘
                        │  ▲                    │
                        │  │                    │
                        │  └────────────────────┘
                        │     (下一轮继续)
                        │
                        ▼
                  ┌──────────────┐
                  │  PAUSED      │
                  │  暂停        │
                  └──────────────┘
```

### 回合级状态机 RoundState

```
┌──────────────┐     ┌──────────────────┐     ┌──────────────┐
│  DEALING     │────>│  RESPONSE_OPEN   │────>│  VERIFYING   │
│  翻牌中      │     │  反应窗口开放    │     │  验证中      │
└──────────────┘     └──────────────────┘     └──────────────┘
                           │                        │
                           │                        │
                           ▼                        ▼
                    ┌──────────────────┐     ┌──────────────┐
                    │  TIMEOUT         │     │  SETTLED     │
                    │  超时未抢答      │     │  已结算      │
                    └──────────────────┘     └──────────────┘
```

### 玩家状态机 PlayerState

```
┌──────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  IDLE    │────>│  OBSERVING   │────>│  BUZZING     │────>│  WAITING     │
│  空闲    │     │  观察中      │     │  抢答中      │     │  等待结算    │
└──────────┘     └──────────────┘     └──────────────┘     └──────────────┘
                                                                    │
                                                                    ▼
                                                             ┌──────────────┐
                                                             │  PENALTY     │
                                                             │  罚停中      │
                                                             │  (待确认)    │
                                                             └──────────────┘
```

## 关于铃铛模式的说明（待确认）

市场上存在"加铃铛"与"不带铃铛"的冲突版本（C 级）。在数据模型中应保留 bell_enabled 标志位以支持两种模式，但具体实现方式需等待官方确认。

## 待确认的数据字段

| 字段 | 所属模型 | 疑问 |
|------|----------|------|
| total_rounds | Game | 是否有固定回合数，还是打到目标分数即止？ |
| penalty_count | Player | 错误次数上限？连续错误是否有额外惩罚？ |
| cards_displayed | Round | 每回合展示几张牌？是否所有玩家看到相同牌面？ |
| response_window | Round | 反应窗口时长是多少？是否固定？ |
| special_effect | Card | 是否存在特殊效果卡牌？ |
| bell_enabled | Game | 铃铛模式与无铃铛模式的具体差异？ |
