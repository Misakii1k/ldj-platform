## 审核标准与铁律
1. **严格正整数**：1..999,999,999,999，禁止浮点数、负数、0、科学计数法；
2. **确定性统计口径**：每题必须限定年份/官方测量标准/行业公报，杜绝模棱两可；
3. **真实可查外部来源**：必须提供公开权威网址（政府机构、联合国、NASA、国际体育单项组织、学术机构或权威百科）；
4. **原创题面**：不抄袭受版权保护的商业题卡，使用自有中文表述。
