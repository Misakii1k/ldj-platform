## 设计说明

- **提交后落库**：`enqueue_adjudication` effect 在 reduce 只声明任务参数，session 层只登记 receipt（kind `'none'`、receiptId=taskId）并校验参数（sessionId 归属、submittedAtSeq≥1、摘要非空）；真实落库由 `executor` 的 `postCommit` 回调在房间事务 **COMMIT 之后**调用 `taskQueue.handleCommitted` 完成。任务创建失败被吞掉，不影响已提交房间事务。
- **独立队列**：任务轮询/调度（含慢模型调用）在 `AdjudicationTaskQueue` 自己的单线程轮询循环上运行，绝不入 executor 的 `RoomQueues`（房间事务队列）；只有结果回灌本身经 `executor.executeInternal` 进入对应房间串行事务链。因此 `queue.ts` 无需改动（`RoomQueues` 已支持独立实例，任务队列自持轮询即满足「第二个独立队列」语义）。
- **exactly-once**：`applyTaskResult` 事务内先按行状态认领——已 `done`/`discarded` 直接丢弃；会话已结算 → 标记 `discarded`；否则 `running/pending → done` 并持久化 `result_json`、擦除 `input_plaintext_json`。提交后仅对 `done` 且会话未结算的任务走 `external_task_result` 回灌。`done` 状态即「已回灌标记」（持久化在任务行），重放/重启不再调用模型、不重复回灌。
- **恢复续跑**：`runStartupRecovery` 步骤 5.5 调 `settleAdjudicationTasks`：FINISHED/ABORTED 会话的 pending/running/errored 任务 → `discarded`；活动会话的 running/errored → 重置 `pending`（服务就绪后由 taskQueue 续跑）；`done` 任务保持不动。

1. **~~pre-existing typecheck 错误~~ 已解决**：`packages/server/tests/helpers/fullGameDriver.ts:235` 的 `gameId` 类型收窄问题（`FullGameMatrixOptions.gameId` 含 landlord/werewolf 传入 `createDriver('uno' | 'undercover')`）由并行 TOOLS 门在白名单内扩展该文件（`gameId` 支持 werewolf/landlord）顺带修复；协调器最终 `npm run typecheck` 0 错误。
2. **app.ts 未接线（白名单不含 app.ts）**：生产路径的 `RoomCommandExecutor` 构造未传 `postCommit`，`AdjudicationTaskQueue` 也未在 app 中构造/start。本门测试直接接线验证全部行为；D4-A2（runner）或后续接线窗把 `dispatchTask`（真实模型）与 postCommit 钩子接入 app。计划文件白名单未含 `app.ts`，故本门不触碰。
3. **`versionedRecovery.ts` 对账缺口（白名单外）**：`reconcileEffects` 只识别 `system_message` / timer effect，`enqueue_adjudication` effect（receipt kind `'none'`）若出现在被重放的 trailing event 信封中会走 `reconcileTimerEffect` 抛错（会话 ABORTED）。`versionedRecovery.ts` 不在本门白名单，未改动。当前场景下任务信封只在提交后立即落库、快照与 last_seq 同步，故不触发；D4-B/后续应为其增加 `'none'` receipt 的对账分支。
4. **崩溃窗口 at-most-once**：`applyTaskResult` 先置 `done` 再回灌；「置 done 后、回灌前」崩溃会导致结果丢失（不重复回灌，与计划 exactly-once 语义一致：同 task_id 只回灌一次）。已在代码注释与测试中断言。
5. **queue.ts 未修改**：计划允许「第二个 RoomQueues 实例或第二张 map」；本实现以 taskQueue 自有轮询循环承担独立队列，`RoomQueues` 无需变更（若协调器要求字面修改可追加说明性工厂）。
