# D4-F1 多规则集注册与会话身份结果

## 范围

把注册表从模块级升级为 `(gameId, rulesetId)` 元组，`game_sessions` 以 `ruleset_id` 为权威规则身份（migration v7 重建并回填），服务端/恢复/广播/机器人/计时器全链路按会话规则集解析。

## 交付物

### 共享规则集注册表

- `packages/shared/src/game/rulesetRegistry.ts`：纯函数注册表（无 I/O、无 zod）。
  - `buildRulesetRegistry`：重复元组、空 ID、缺默认、多默认、空游戏一律拒绝；输入不可变。
  - `resolveRulesetIdentity`：config.rulesetId 已注册则采用，缺省用默认，存在但未注册则抛错。
  - `listRulesetIdsForGame`。
- `packages/shared/src/game/catalog.ts`：`buildCatalogRulesetRegistry` + 模块加载期 `CATALOG_RULESET_REGISTRY` 校验；狼人目录补登 `werewolf_platform_open_kill_v1`（与准入台账一致）。
- `packages/shared/src/game/versionedContract.ts`：`GameModuleV2` 新增必填 `registeredRulesets` / `defaultRulesetId`；UNO/卧底 V2 模块适配。
- 测试 `packages/shared/tests/rulesetRegistry.test.ts` 8 项。

### Migration v7（`add-session-ruleset-identity`）

- 重建 `game_sessions`：新增 `ruleset_id TEXT NOT NULL`、`failure TEXT`、`failure_details_json TEXT`；status CHECK 增加 `SUSPENDED`；唯一活动索引覆盖 `SUSPENDED`。
- `ruleset_id` 回填优先级：V2 信封 `$.rulesetId` → 按 module_id（undercover/uno/landlord 冻结常量；werewolf 按 `config.rulesetId` 识别 open-kill，否则 legacy 基线）→ `unregistered_module`。
- 仅仍处于活动态（PREPARING/ACTIVE/RECOVERING）的未注册模块会话标 `SUSPENDED + FAILED_RULESET_UNAVAILABLE`；v5 已 ABORTED/FINISHED 的历史行不反转。
- `migrator.ts`：每个迁移事务外 `PRAGMA foreign_keys=OFF`/事务后恢复（表重建需要 DROP 被外键引用的父表；PRAGMA 在事务内是 no-op）。公开 API 与 1–6 行为不变；迁移尾部 `foreign_key_check` 哨兵，违规即整条回滚。
- 测试 `packages/server/tests/migrationV7.test.ts` 9 项；`persistence.test.ts` 断言更新为 v7 语义。

### 会话级规则集解析（服务端全链路）

- `packages/server/src/core/game/registry.ts`：元组注册表；`getDefaultRuleset(gameId)`、`getGameModule(gameId, rulesetId?)`（省略时默认规则集，兼容旧调用）、`getSessionGameModule(session)`（以持久化 ruleset_id 为权威，缺失/未注册即 undefined → 失败关闭）、`resolveRulesetForStart(gameId, config)`。狼人 legacy 模块双注册（legacy + open-kill）。
- `session.ts`：`SessionRow` 增加 `ruleset_id`/`failure`；`getActiveSession` 覆盖 `SUSPENDED`；`requireSessionModule` 会话级解析；`startGame` 解析并持久化 `ruleset_id`，且把 `rulesetId`（平台元数据）从传入模块 `parseConfig` 的配置中剥离（strict 模块 schema 不接受该键）。
- `views.ts` / `botRunner.ts` / `recovery.ts` / `ws.ts`(autoStart) / `fullGameDriver.ts`：全部改走会话级/默认规则集解析；恢复失败新增 `ruleset_unavailable` 原因码。
- 集成测试 `packages/server/tests/sessionIdentity.test.ts` 5 项：startGame 持久化、未知规则集开局失败、狼人双规则集、默认规则集、SUSPENDED 活动位与解析失败关闭。
