## 规则基线

### 铃铛对决 bell_clash_v1（原版《Ding! 眼急脑快》）
| 项 | 内容 |
|---|---|
| 机制 | **UNO 式出牌（同色/同数字）+ 行动短语卡 + 按铃抢回合**；每人 8 张先打完者胜（证据 C 级，纠正资料库"图案/颜色抢答"误判） |
| 按铃 | 有人说了/做了牌上内容 → 拍铃者接管回合打出同色短语卡；错误拍铃罚摸一张并关窗；无人拍铃计时器兜底 |
| 牌库 | **平台原创设计**（4 色×数字 1-8 各 2 张 + 每色自编短语卡 2 张），不复制原版牌表 |
| 平台裁定 | 错误拍铃罚摸；抽牌堆耗尽 → 手牌最少者胜（原版 UNO 重洗弃牌堆，本实现状态未存弃牌堆全体） |

### 伪人测试 echo_judge_v1（原版判官模式）
| 项 | 内容 |
|---|---|
| 机制 | 判官出题 → 秘密分配身份 → 伪人获触发词卡 → 依次回答（人类可说谎、伪人藏词）→ 判官指认（证据 B/C 级） |
| 计分 | 判官抓对 +1 / 抓错 −1（平台裁定）；被抓伪人 −1；隐藏成功 +2 |
| 轮换 | 判官按座位轮换**跳过伪人**（伪人不能当判官）；所有人类各当一次判官后结束，最高分获胜 |
| 平台裁定 | 伪人数量按人数档（3-4:1、5-8:2、9-12:3）；触发词库原创；高分/团队模式标注后续扩展 |
