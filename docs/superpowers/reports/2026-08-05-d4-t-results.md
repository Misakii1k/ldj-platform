# D4-T 标准桌面视角契约结果

## 范围

定义并严格校验标准桌面视角 v1 契约（纯 shared 层），服务端 `game_state` 可选下发 `tabletopVersion + tabletop`，客户端严格解析失败关闭；不实现任何 UI、不改变既有游戏 inner view 字节。

## 交付物

### 共享契约

- `packages/shared/src/game/tabletop/contract.ts`：`StandardTabletopViewV1`、`TABLETOP_VIEW_VERSION=1`、`MAX_PUBLIC_LOG_ENTRIES=50`；phase（code/sequence）、round、turn（mode/actors）、seats（真实 seat + participation/activity）、clock（唯一 token + deadlineAt）、`availableCapabilityIds`、有界 `publicLog`（revision + entries）、operations（queued/processing/error + retryCapabilityId）、result（provisional/final/aborted/failed）。
- `packages/shared/src/game/tabletop/capabilities.ts`：版本化封闭能力枚举（15 个，含 canPlayCard/canDraw/canCallUno/canCatchMissedUno/canStackPenalty/canChallenge/canAcceptPenalty/canGuessWord/canSkipFinalGuess 等）；未知能力按契约错误。
- `packages/shared/src/game/tabletop/parse.ts`：`parseTabletopView` 严格解析（必填字段、无未知键、枚举闭合、能力白名单、log 有界、retry 能力校验）。
- `packages/shared/src/game/versionedContract.ts`：`GameModuleV2` 新增**可选** `tabletopProjection`（player/spectator 标准视角 + public event → log 摘要）；不强制既有模块，legacy 路径完全不变。
- shared exports 接线。

### 服务端

- `packages/server/src/core/game/views.ts`：`GameStatePayload` 增加可选 `tabletopVersion/tabletop`；模块声明 projection 时由平台调用 player/spectator 投影并经 `parseTabletopView` 严格校验后下发（失败关闭）；未声明时不下发（legacy 帧字节不变）。

### 客户端

- `packages/client/src/game/types.ts`：`parseGameStatePayload` 对携带 `tabletop` 的帧严格解析（版本一致 + `parseTabletopView` 通过），畸形/未知版本失败关闭；无 tabletop 的 legacy 帧照常通过。

## 测试

- `packages/shared/tests/tabletop.contract.test.ts`（6 项）：合法视角解析、未知字段/缺失/版本拒绝、未知能力与非法枚举、log 有界与条目校验、operations retry 能力白名单、结果状态闭合。
- `packages/client/tests/tabletopPayload.test.ts`（3 项）：合法 tabletop 帧、legacy 无 tabletop 帧向后兼容、版本不匹配/畸形失败关闭。
