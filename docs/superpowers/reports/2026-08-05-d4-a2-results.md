## 冻结行为

### 归一化

顺序固定为：折叠前拒绝 Cc/Zl/Zp → NFC → Unicode whitespace 折叠为单个 ASCII 空格 → trim → 仅 ASCII A-Z lowercase。

- 长度在归一化后按 Unicode code point 计数，允许 1–64；non-BMP 计 1。
- 换行、tab、控制字符和 Unicode 行/段分隔符失败关闭为非法任务输入。
- 空白-only 输入归一化为空后拒绝，不能本地误判为等价。
- 不做简繁转换、同义推断或标点消除。

### 结构化裁决

分类集合仅为：

- `equivalent`
- `not_equivalent`
- `uncertain`
- `provider_error`
- `timeout`
- `invalid_response`

`equivalent` / `not_equivalent` 为终局；其余四类触发备用。备用仍非终局时 verdict 固定为 `not_equivalent`、source 为 `fail_closed`。

模型响应仅接受无额外字段的 `{ "classification": "..." }`：既支持真实 LLM 返回的严格 JSON 文本，也支持已解析对象；裸字符串、Markdown fence、空文本、多余字段、未知类别和非 JSON 均映射 `invalid_response`。

## 只读审查与延期项

当前 A2 文件无阻塞性缺陷：policy 无 I/O；runner 不直写权威状态；主备隔离、结构化分类、有限日志、A1 JSON 持久化兼容和重复回灌丢弃均由代码与测试证实。

以下两项是 **D4-B 启动前必须纳入授权与测试的边界修复**，已回写批准计划：

1. **永久非法任务热重试**：A1 `taskQueue` 会把 dispatch 抛错标为 `errored`，而 `nextPendingAdjudicationTask` 又立即选择 `errored`，可能在同进程形成无退避热循环。B 必须加入持久 attempts、有界退避/重试上限和永久非法输入的可诊断终态。
2. **超时取消传播**：A2 runner 当前以 `Promise.race` 确定性映射 `timeout`，但 invoker 契约尚无 `AbortSignal`，不能主动终止真实底层请求。B 生产接线必须扩展 invoker 取消契约，并测试 primary/fallback 超时均真正 abort。

同时保留 A1 已知 at-most-once 崩溃窗口：任务置 `done` 后、系统动作回灌前崩溃会丢失结果；该项需与 D4-B trailing-event/recovery 对账一起收口。
