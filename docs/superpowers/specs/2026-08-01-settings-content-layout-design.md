# 设置页内容与排版优化设计

## 目标

优化平台设置弹层的信息层级、内容组织和响应式排版，降低 AI 配置的认知负担，并让界面效果与背景主题更容易查找和调整。

本次保留现有设置能力、服务端接口、持久化方式和即时生效逻辑，只调整客户端的信息架构、内容文案、组件组织和交互呈现。

## 设计方向

采用侧栏三分类与渐进式配置方案。

- 桌面端使用左侧固定分类导航和右侧内容区。
- 移动端将分类导航转换为顶部横向切换栏。
- 分类固定为“AI 引擎”“界面效果”“背景主题”。
- 默认打开“AI 引擎”。
- 常用状态与操作优先展示，高级参数按需展开。

## 弹层结构

弹层标题为“平台设置”，说明文案为“管理 AI、动效与背景主题”。

桌面端整体结构：

1. 左侧分类导航，占据稳定窄栏。
2. 右侧分类标题与简短说明。
3. 右侧可滚动内容区。
4. 分类切换不关闭弹层，也不丢失当前表单状态。

移动端整体结构：

1. 标题区域保持在顶部。
2. 分类导航改为横向滚动或等宽标签栏。
3. 内容区保持单列布局。
4. 操作按钮在窄屏下纵向排列或保持可触达的双按钮布局。

## AI 引擎

AI 引擎分类采用渐进式信息层级。

### 首屏内容

依次展示：

1. 运行状态卡：当前是否可用、服务商、模型和最近一次连接测试结果。
2. 服务预设：当前配置、DeepSeek、Claude、Ollama 和自定义预设入口。
3. 快速连接：API Key、测试连接、保存并启用。
4. 当前模型：直接展示并允许编辑或选择。
5. 高级连接与推理设置：默认折叠。

### 高级设置

展开后提供：

- 服务商接口协议
- 接口地址 Base URL
- 模型目录刷新与手动输入
- 思考深度
- 单次决策超时
- 管理员口令
- 已保存密钥的清除与撤销

高级设置仍复用现有状态和请求逻辑，不改变请求体、共享类型或服务端契约。

### 状态反馈

- 加载时保留内容骨架或禁用状态，避免布局跳动。
- 测试连接时只禁用相关操作，并显示测试中状态。
- 保存时禁用重复提交。
- 成功信息继续通过全局提示展示。
- 错误信息显示在 AI 分类内，并与相关字段建立可访问性关联。
- 配置发生变化后，旧诊断结果明确标记为已过期。

## 界面效果

界面效果分类只承载动效偏好。

顶部状态区域展示：

- 当前实际动效等级
- 当前选择的偏好
- 自动降级原因

动效选项保持四种：

- 自动调节
- 完整动效
- 轻量动效
- 关闭动效

选项使用紧凑选择卡呈现。系统“减少动态效果”、节省流量、设备能力和运行时卡顿导致的降级说明放在状态区域，不与选择项重复堆叠。

## 背景主题

背景主题独立于动效设置，每个主题卡展示：

- 主题名称
- 简短视觉描述
- 性能或设备适用提示
- 当前选中状态

保留四种现有背景：

- 温馨派对插画
- 霓虹流光与粒子
- 深邃极光或视频
- 极简纯色

选择后即时预览并沿用现有浏览器本地持久化逻辑。

## 组件边界

`SettingsSheet` 负责弹层分类状态和三类内容的装配，不承载具体设置业务。

建议拆分为：

- `SettingsNavigation`：分类导航与键盘切换。
- `AppearanceSettings`：动效状态与偏好选择。
- `BackgroundSettings`：背景主题选择。
- `AiEngineSettings`：保留 AI 请求和表单状态管理。
- AI 内部现有状态、预设、快速连接、模型选择和诊断组件继续复用。

不进行与设置页无关的组件或样式重构。

## 可访问性

- 弹层打开后初始聚焦关闭按钮或当前分类标签，不跳转到内容中段。
- 分类导航采用标签列表、标签和标签面板语义。
- 支持方向键切换分类，Tab 进入当前分类内容。
- 所有按钮、标签和选择卡的最小触控尺寸为 44px。
- 选中状态不能只依赖颜色表达。
- 错误字段使用 `aria-invalid` 和 `aria-describedby` 关联错误信息。
- 保持 Escape 关闭和关闭后的焦点归还。

## 响应式规则

- 宽屏：侧栏与内容区双列，内容卡片可按现有字段宽度使用双列。
- 中等宽度：侧栏保持，内容字段逐步改为单列。
- 窄屏：顶部分类栏与单列内容，弹层保持底部抽屉形态。
- 分类导航、主要操作和危险操作在任何宽度下均不可横向溢出。

## 样式策略

- 延续现有纸张、墨线、珊瑚红和绿色状态色，不引入新视觉体系。
- 统一设置区域使用现有首页设计令牌，避免继续混用通用与首页颜色变量。
- 清理仅与旧设置布局相关且确认无引用的样式类。
- 保持移动优先、减少动态效果和安全区规则。

## 测试与验收

### 自动验证

- TypeScript 类型检查通过。
- ESLint 检查通过。
- 现有客户端和服务端测试通过。
- 为可抽离的分类状态、键盘切换和展示决策补充纯函数测试。

### 浏览器验证

- 桌面端打开设置后显示侧栏三分类。
- 移动端显示顶部分类栏且内容无横向溢出。
- 三个分类切换正确且不丢失 AI 表单状态。
- AI 首屏按状态、预设、快速连接、模型和高级设置排序。
- 高级设置可展开和收起。
- 动效与背景选择即时生效。
- 加载、测试、保存、错误、成功和诊断过期状态均可识别。
- 键盘可完成打开、分类切换、表单操作和关闭。
- 至少进行桌面与移动端两轮烟雾测试。

## 非目标

- 不新增设置后端接口。
- 不修改 SQLite 设置结构。
- 不改变 API Key 只进不出的安全约束。
- 不增加独立设置路由。
- 不扩展设置在房间或对局中的入口。
- 不重构整个全局样式文件。
