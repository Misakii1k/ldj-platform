# 海龟汤 M1 设计备忘

日期：2026-08-26  
状态：仅设计，本轮不建模块、不改创意工坊预设。

## 不要把现有预设当产品

`party-sandbox` 的 `sea_turtle_soup` 只是一键摆桌：汤面和汤底写在同一张公开卡上，观战也能看见答案，没有主持/猜者隔离，也没有是/否协议。下一阶段不要把它升格成 catalog 游戏。

## 下一阶段应新建什么

独立 `turtle-soup` GameModuleV2，成熟度从 M1 起步：

- 主持私密视图藏汤底；猜者只见汤面；观战不见汤底。
- 自由问答，不是狼人杀那种轮流计时 `finish_speech`。
- 主持答语词表：是 / 否 / 无关 / 猜中。
- AI 主持复用本轮已经打通的机器人 `chat_send` + 私密 `getPlayerView`。
- 更近的参考是谁是卧底（发言）+ 暗夜证词（是/否），不是狼人杀夜刀。

## 本轮已交付的共享面

机器人可以在结束发言前先发公屏。海龟汤主持只要在模块里声明 `speech` 或直接走同一条 `applyChatSend`，不必再造聊天通道。
