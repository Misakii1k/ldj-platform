# T03 · 纯时间线与音频清单
依赖 T01；阅读契约 B/C/F。禁止引擎适配和 JSX。

允许新建：
- D:/项目/scripts/measure-werewolf-audio.mjs（只读 WAV/RIFF，跳过未知 chunk，不假设44字节头）
- D:/项目/packages/shared/src/game/werewolfVoiceManifest.ts（公开 metadata，不引 client）
- D:/项目/packages/games/werewolf/server/timeline.ts（纯 helper）
- D:/项目/packages/games/werewolf/tests/timeline.test.ts
可改 D:/项目/packages/shared/src/index.ts 导出；当前 client cue 表只读取。

步骤：
1. 测量 D:/项目/packages/client/public/werewolf-voice 下实际文件，输出 duration/hash/cue 分类；查验结果与刀口提示禁止放公共清单。
2. 设计纯函数 buildNightPlan(configuredRoles,day,pace)、enterStep/advance/pause/resume 的输入输出；只接 now 参数，不访问时钟/DB，不消费 random。
3. 固定顺序与窗口；open 可多 cue 子环节，完整 action 窗口单独开始。死角色仍入计划；缺角色不入计划。
4. id/revision 单调；pause/resume 旧 token 失效；冻结剩余时间。无 active deadline 的 confirm/day 不产生 timer。
5. 测试全部 pace、角色组合、首夜/次夜、提前/重复/旧 timeout、时刻边界。让 clock.now 一次跳到 deadline，不真实等30秒。
6. 自动推进只生成下一步/待结算信号，不执行 kill/revive/winner。结算由各规则适配器负责。

运行：node scripts/measure-werewolf-audio.mjs（输出文件路径由脚本明确报告）；npx tsx --test packages/games/werewolf/tests/timeline.test.ts；npm run typecheck。
验收：测量结果可重复；所有纯函数无副作用；同输入相同输出；总时长=各cue实测+各窗口，不叠加旧随机间隔。
