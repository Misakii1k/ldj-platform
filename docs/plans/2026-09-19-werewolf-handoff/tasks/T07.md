先读现有内部命令入口/事务队列；已有能力足够时只新增测试，不强行改通用内核。

a. 接入：presence 发现 moderator 断线，经内部命令链触发暂停，校验当前 session 身份；房主断线不是主持断线时不能误暂停。timer dispatch 必须含当前 revision，旧 session 的 timer 不落入新局。
b. 恢复：持久 DB 测试暂停、自动窗口、已交动作；关闭 app 再用同测试数据库重启。旧局仍旧流程；新局只推进当前过期环节，后续窗口给完整时长；重放不能产生双重击杀/系统消息/任务。
c. 真实三客户端：公共 timeline 一致、player view 各自保密；测试主持断线与 timer 同时发生的串行顺序、重连等待手动恢复。检查 private chat 在恢复 receipt/resync 中也不泄露。

运行：npx tsx --test packages/server/tests/werewolfTimelineRecovery.test.ts packages/server/tests/werewolfModeratorSession.test.ts packages/server/tests/werewolfV2Validation.test.ts packages/server/tests/recovery.test.ts；再跑 T02 与两套游戏测试；npm run typecheck。

必须：恢复后 timer token 不复用，旧 timeout 至少重放两次仍无副作用。每个测试 app.close()/socket.close() 在 finally，退出进程无需强杀用户 Node。
