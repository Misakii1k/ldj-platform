# T11 · 角色演出与当前段音频
依赖 T08/T09；阅读契约 F 和 02-VISUAL.md 第4节。分视觉与音频两轮。

允许写：D:/项目/packages/client/src/game/werewolf/ui/RoleTurnOverlay.tsx（新）、WerewolfStage.tsx、useJudgeVoice.ts、judgeVoiceDirector.ts、judgeVoice.ts；D:/项目/packages/client/src/game/werewolf/werewolf-native.css；相应 moderator 页面仅挂载同组件；D:/项目/packages/client/tests/werewolfTimelineVoice.test.ts（新）、werewolfJudgeVoice.test.ts、werewolfJudgeVoiceDirector.test.ts。

步骤：
1. 通用职业层只接 public timeline，不接 self/seat/target；共享同一角色映射。入450ms→突出1500ms→轮廓→出350ms；日夜交叉900ms；不挡点击。
2. 低高横屏保留剪影；reduced motion≤120ms；后台暂停，退出无 RAF/audio/listener。
3. 新局语音只播放当前 cue，按 clock 定位。新段/暂停/手动/隐藏取消旧音频及回调，异步加载晚回来不能播放过期句子。
4. 默认出声设备按 host/moderator；本机可开启；手动主持永不自动播报。旁端只字幕并非故障。
5. 自动播放受限/404/音量0有字幕兜底与启用提示，不发推进命令、不改时限。重连不补播之前整夜。
6. 旧局保留旧 director 分支，不能把新 timeline 支持又接回原整夜队列。公共 cue 不允许 seer_good/seer_wolf/刀口。

运行：npx tsx --test "packages/client/tests/werewolf*Voice*.test.ts"；npm run typecheck；npm run build。
证据：模拟 audio 单测 + 浏览器 media 事件/当前段 id + 实际可听音频检查分开报告。headless 的 play 成功不等于人耳听过。
