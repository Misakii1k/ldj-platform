# UNO 视觉契约 · 整屏色块

像素参照：`docs/ui-preview/cards-trio/r2/uno-1-play.html`、`uno-2-result.html`
共用样式参照：`r2/_party.css`、`r2/_party.js`（**Ding 也用这一套**，所以 T2 先把它做成共用组件）

适用 ruleset：`uno_platform_house_v1`（欢乐房规，`game/uno/stage/UnoHouseStage.tsx`）。
经典单局 `uno_legacy_platform_v1`（`UnoLegacyGamePage.tsx`）**本次不改**。

## 1. 设计方向

- 隐喻：**糖果色纸板游戏盒**的"整屏色块"版——当前颜色就是整张桌布（45° 宽条纹 + 四周暗角 + 桌布上 10% 透明的大号牌型剪影），中央一块纸板圆盘（年轮纹 + 内圈当前色光晕），牌堆与弃牌在圆盘上；对手是贴纸，沿上半圈排开；外圈一条虚线方向环慢转，反转时掉头。
- 档位：平面。不开 `.stage-felt-3d`（现在 UNO 开着，**关掉**）。
- 表皮：浅色派对。
- 对标：Balatro 的打击感。
- 关键演出：**换色时新颜色从弃牌堆位置圆形泼满全屏**（560ms），这是本款的签名。

## 2. 状态模型（`UnoHousePlayerView`）

| 字段 | 驱动的画面 |
|---|---|
| `currentColor` | 桌布颜色 + 泼色；圆盘内圈光晕；HUD"当前：红"色块 |
| `topDiscard` | 弃牌堆顶；上一张压在下面露一角（随机 ±10° 倾斜） |
| `direction` | 方向环顺 / 逆时针；变化时方向环放大弹一下 |
| `currentPlayerId` | 当前玩家贴纸放大 1.1 + 黄色外框 + 头像外一圈虚线慢转；圆盘上方阶段牌"轮到你 / 等别人出牌" |
| `players[].handCount` / `unoCalled` | 贴纸上张数（前面画一个小牌背图标）；剩 1 张时贴纸变粉 + 右上角红色"UNO!"小标签晃动 |
| `pendingPenalty` | 被罚的人贴纸上方 "+2 / +4" 数字从牌堆飞过去；罚牌窗口倒计时走 HUD 环 |
| `unoRaceWindow` | 抓漏喊 UNO 窗口：沿用现有逻辑，外观按钮换成本套样式 |
| `deckCount` | 牌堆下方小标签"剩 N 张" |
| `round` / `roundLimit` / `cumulativeScores` | 左上"第 2 / 3 局 · 累计 34 分" |
| `clockInfo.turnDeadlineAt` / `windowDeadlineAt` | 圆盘下方 HUD 的倒计时环 |
| `me.hand` / `me.playableCardIds` | 底部手牌；能出的牌外加一圈奶油色描边，不能出的压暗（饱和度 0.55、亮度 0.92） |
| `phase = round_over` + `roundResults` 最后一项 | 画面 ② 本局结算 |
| `phase = match_over` + `matchRanking` | 沿用画面 ② 的计分板，标题改"总榜"，第一名金边 + 胜利爆发（现有 `TabletopVictoryBurst`） |

**数据缺口（T3 里补）**：画面 ② 要把每个人的剩牌**逐张翻开**，但 `roundResults` 只有 `perPlayerTotals`（分数），没有剩牌内容。在 `packages/games/uno/server/house/types.ts` 的 `UnoHouseRoundResult` 加 `remainingHands: readonly (readonly UnoHouseCard[])[]`（按 `players` 顺序，出完的人是空数组），`settleRound` 里填上；客户端解析器同步。**结算后公开剩牌是正常规则**（本来就要亮牌算分），不涉及隐私问题，但对局中视图不能出现这个字段。

## 3. 色值

在 `.pt-table`（派对桌共用根类，T2 建）里定义一次：

| 变量 | 值 | 用途 |
|---|---|---|
| `--pt-red` / `--pt-yellow` / `--pt-green` / `--pt-blue` | `#e8483b` / `#f7c84b` / `#3fb57a` / `#3d8fe0` | 牌面语义色 + 桌布色 |
| `--pt-kraft` / `--pt-kraft-light` / `--pt-kraft-dark` | `#d9b98a` / `#ead2a8` / `#b8945f` | 纸板圆盘 |
| `--pt-cur` | 随 `data-color` 取上面四色之一 | 当前色 |
| `--pt-floor` | 泼色结束后写入 | 桌布底色（泼色期间还是旧色） |

注意：`--pt-yellow` 与 `--gp-yellow` 数值相同但语义不同——牌面黄用 `--pt-yellow`，主按钮黄用 `--gp-yellow`。
墨线、奶油纸、阴影、珊瑚红一律平台令牌。

## 4. 两张关键画面 + 牌多规则

### 4.1 画面 ① 出牌（`uno-1-play.html`）

- **桌面 1280×800**：
  - 圆盘 450×450，圆心在 (50%, 44%)；方向环 540×540 同心。
  - 牌堆（背面 108px 宽，底下两层错位黑色厚度）在圆心左 22px + 108px 处，弃牌在右侧，间距 44px。
  - 阶段牌在圆心上方 218px（衬线 26px，奶油卡纸，倾斜 −2°）；HUD（当前色 + 倒计时环）在圆心下方 160px。
  - 对手贴纸：上半圈椭圆 rx 400 / ry 280，角度在 −100° … +100° 之间均分（12 点方向为 0°），每张随机 ±1.5–3.5° 倾斜。
  - 左上局数标签；左下我的贴纸；底部手牌一行（86px 宽）+ 操作坞「摸牌 / UNO!（黄）」。
- **手机竖屏 390×844**：
  - 圆心移到 (50%, 40%)；圆盘 226；方向环 272；牌堆 / 弃牌 74px 宽；阶段牌在圆心上方 156px（18px 字）；HUD 在下方 104px。
  - 对手贴纸 rx 150 / ry 244，角度 −72° … +72°；**手机上贴纸去掉头像**，只留名字 + 张数。
  - 我的贴纸在手牌上方居中；手牌 60px 宽。
- **演出**：
  - 出牌：牌从手里飞到弃牌堆（抬 180px、转 16°、520ms），落地弹一下，上一张压到下面。
  - 功能牌：`+4` → 中央 220px 放大残影 + 冲屏四色渐变"+4"（衬线 190px）+ 4px 屏震 → 弹选色盘；`变色` → 残影 + 选色盘；`反转` → 冲屏"反转！"+ 方向环掉头；`跳过` → 冲屏"跳过！"；`+2` → 冲屏"+2" + 3px 屏震。冲屏背后是当前色放射光。
  - 罚牌：黑底白字 "+2 / +4" 小胶囊从牌堆飞到被罚者贴纸，贴纸下方冒气泡"摸 2 张"，张数滚动。
  - 换色：从弃牌堆中心圆形泼开 560ms，泼满后桌布底色才换。
  - 选色盘：半透明遮罩 + 奶油卡纸面板，四个 116×92 色块按钮，悬停上浮倾斜。
  - 摸牌：背面从牌堆飞到手里，落地变正面弹一下；牌堆"剩 N 张"减一。
  - 手里剩 1 张时「UNO!」按钮左右晃。
  - 倒计时 ≤10 秒变黄、≤5 秒变红 + 脉冲。

### 4.2 画面 ② 本局结算（`uno-2-result.html`）

- **桌面**：圆盘缩到 400 移到左侧（圆心 27%, 50%），上面放出完的人：120px 大头像 + 衬线 40px"可可 出完了！"+ 黑底小标签"本局 0 分"；右侧 640px 宽计分板（奶油卡纸）：表头「名次 / 玩家 / 剩牌 / 本局 / 累计」，每人一行；右下「看总榜 / 下一局（黄）」。牌堆、弃牌、方向环、对手贴纸、手牌在结算时都隐藏。
- **手机竖屏**：圆盘 250 在上方（20%），胜者叠在圆盘上；计分板 370 宽在下方；按钮贴底居中；计分板列变窄（名次 22 / 玩家 78 / 剩牌 1fr / 本局 48 / 累计 48），头像与"本局 / 累计"小字隐藏。
- **演出**：进场冲屏"UNO!" + 3px 屏震 → 计分板逐行入场（左滑 + 淡入）→ 每行剩牌逐张翻开，本局分跟着逐张往上跳（每张上方飘一个红色"+N"），万能牌那张停顿更久、分数 ≥50 时 2px 屏震 → 本局分跳完后累计分跳 → 全部跳完后按累计分**动画换位**重排（FLIP，480ms），第一名金边 + 名次前小星。
- 计分规则（服务端已实现，只做展示）：数字牌 = 面值，跳过 / 反转 / +2 = 20，变色 / +4 = 50，出完的人 0 分；累计分低者名次靠前。

### 4.3 牌多规则（手牌 ≥ 约 12 张）

用户原话：「其余两个需要考虑牌多的时候的展示效果」→ 选「**自动收紧，只露角标**」。

- 算法照搬 `r2/_party.js` 的 `fitHand`：`overlap = min(基础重叠, -(牌宽 - (可用宽 - 牌宽) / (张数 - 1)))`；桌面可用宽 820、基础 −24；手机可用宽 350、基础 −20。
- 露出宽度 < 牌宽 × 0.42 时进入**紧凑模式**（`.tight`）：扇形倾斜收到 0.5°；左上角标放大到牌宽 × 0.24；牌面光泽去掉。
- 手牌**按颜色归堆**：红 → 黄 → 绿 → 蓝 → 万能，同色内保持服务端顺序。
- 紧凑模式下：电脑悬停这张牌上抬 40px、放大 1.06、右侧让出 36px（手机 26px）完整露出；**手机第一次点 = 抽出来看，第二次点才出牌**（待确认 Q1）。
- 现有 `shared-ui/denseHandLayout.ts` 的"可出牌抬升 + 不可出压成色条 / 双排兜底"策略**不再用于 UNO 欢乐房规**：`CardFanEngine` 加可选 prop `crowdMode?: 'dense' | 'corner'`（不传时沿用现有 `denseWhenCrowded` 的行为，完全不变）；UNO 房规去掉 `denseWhenCrowded`、改传 `crowdMode="corner"`。经典单局和其他游戏不受影响。
- 验收：7 / 16 / 25 张三档，桌面和手机都**不出现横向溢出**、手牌不超出屏幕、不与我的贴纸 / 操作坞重叠。

## 7. 不照抄

- 方向稿工具条、手牌张数切换是预览用。
- 方向稿里对手自动出牌是演示；正式版由服务端事件驱动（现有 `useUnoHouseStage.tsx` 已有事件差分，接进去即可）。
- 方向稿的对手头像是字母圆；正式版用 `UserAvatar`。
- 方向稿没画罚牌叠加窗口、质疑 +4、抓漏喊 UNO 三个房规窗口：**沿用现有逻辑和交互**，只把按钮 / 面板换成本套样式（奶油卡纸 + 粗墨边 + 黄色只给主按钮）。如果换样式时发现布局放不下，停下来问。
