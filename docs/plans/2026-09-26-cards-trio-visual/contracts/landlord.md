# 斗地主视觉契约 · 老茶馆正堂

像素参照：`docs/ui-preview/cards-trio/r2/landlord-1-bid.html`、`landlord-2-play.html`、`landlord-3-result.html`
共用样式参照：`r2/_teahouse.css`（场景 / 席位 / HUD / 横屏）、`r2/_poker.css`（牌面）、`r2/_teahouse.js`（场景 SVG、手牌收紧算法）

## 1. 设计方向

- 隐喻：**坐在老茶馆正堂的八仙桌前打牌**。第一人称视角，面前是透视的木桌（桌心一块朱红毡），远处是墙、梁、梁托、灯笼、对联、牌匾、花窗、墙裙。
- 档位：**平面 + 一张透视桌面**（桌子用 `perspective` + `rotateX(46deg)`，其余元素是平面贴在上面）。不开共享 `.stage-felt-3d`。
- 表皮：浅色派对（粗墨边 + 硬投影）。
- 对标：狼人杀的"场景即世界"；打击感参照 Balatro（只取演出和牌的手感）。
- **只做横屏**：手机竖屏盖一层"请把手机横过来"，不做竖屏布局。

## 2. 状态模型（`packages/client/src/game/landlord/types.ts` 的 `LandlordPlatformPlayerView`）

| 字段 | 驱动的画面 |
|---|---|
| `phase` = `bidding` | 画面 ①：桌心三块叫分木牌、底牌背面扣着、操作坞是「不叫 / 1 分 / 2 分 / 3 分」 |
| `phase` = `playing` | 画面 ②：桌心是出牌区（上一手牌 + 标签"某某 · 牌型"），操作坞是「不出 / 提示 / 出牌」 |
| `phase` = `game_over` | 画面 ③：捷报展开、输家剩牌摊开、结果按钮 |
| `bids[]` | 各人名牌上方气泡"1 分 / 不叫"（常驻）；木牌：已被超过的变灰，当前最高的变金色并挂"最高"角标 |
| `currentBidderId` / `currentPlayerId` | 谁的名牌带黄色外框 + 身后呼吸光晕 + 名牌右上角小倒计时环 |
| `landlordId` | 名牌左侧身份圆章：地主 = 朱红底金字"主"，农民 = 浅绿底"农"，未定 = "?"；变化时圆章放大落下 |
| `bottomCards` | 叫分阶段：3 张背面；定地主后：逐张翻开，飞进地主手里，**正面留在桌上**做公开记录 |
| `multiplier` | 右下 HUD 红纸倍数牌 `×N`（衬线大字）。**只等于最高叫分**，出炸弹不变 |
| `currentTrick` | 出牌区的牌 + 标签 |
| `players[].handCount` | 对手名牌上的张数（≤2 张时变珊瑚红），名牌下方背面小扇（最多 8 张） |
| `winnerTeam` / `winnerId` | 捷报大字"地主胜 / 农民胜"，胜方名牌黄框 |
| `deadlineAt` | 我的回合：右下大倒计时环；别人回合：他名牌上的小环 |
| `me.hand` | 底部手牌（大牌在左，同点按花色 ♠♥♣♦） |

**数据缺口（T6 里补）**：画面 ③ 要把输家剩牌翻开，但现在 `game_over` 的视图不带别人的手牌。在 `packages/games/landlord/server/platform/rules.ts` 的 `basePublicView` 里，**仅当 `phase === 'game_over'`** 时加 `revealedHands: Record<playerId, LandlordCard[]>`（终局公开所有人剩牌），客户端解析器同步加可选字段。对局中该字段必须不存在（隐私边界测试要加一条）。

"春天"判定（纯客户端，只用于显示印章）：地主胜，且两个农民在整局里一张都没出过——即 `revealedHands` 里两个农民都还是 17 张。**不影响任何数值**。

## 4. 三张关键画面

所有尺寸都以方向稿为准。手机横屏的具体数值在 `r2/_teahouse.css` 末尾「手机横屏 844×390」一段，逐条照搬。

### 4.1 画面 ① 叫地主 + 翻底牌（`landlord-1-bid.html`）

- **桌面 1280×800**：场景占满；对手半身像在桌对面左右（18% / 82%），像下方是名牌；桌心上方一排底牌（3 张背面，每张约 56px 宽）+ "底牌"标签；底牌下方三块叫分木牌（84×100，衬线 44px 数字）；左中是阶段大字"轮到你叫分"（衬线 36px）+ 一行说明；右中是倍数牌 + 倒计时环；底部手牌一行（17 张，78px 宽，按可用宽度自动收紧）+ 操作坞「不叫 / 1 分 / 2 分 / 3 分（黄）」；左下是我的名牌。
- **手机横屏 844×390**：对手缩成 66px 像 + 小名牌放在左上 / 右上；底牌 30px 宽在正上方；木牌 54×64；阶段字和 HUD 移到手牌上方两侧；手牌 50px 宽；操作坞贴右下。
- **演出**：点叫分 → 对应木牌弹起并变金、比它小的变灰 → 金元宝从上方落到地主名牌、身份圆章盖定（自己是地主时冲屏"你是地主"+ 3px 屏震）→ 底牌间隔 160ms 逐张翻开 → 间隔 90ms 逐张飞进地主手里（飞向对手时缩到 0.5）→ 自己手里新到的 3 张描金边。

### 4.2 画面 ② 出牌（`landlord-2-play.html`）

- **桌面**：同 ① 的场景；桌心是出牌区（上一手牌 72px 宽，互相压 30px）+ 下方标签"阿杰 · 对子"；盖碗茶放在桌面左侧；右中 HUD 是倍数 `×3` + 20 秒倒计时环；操作坞「不出 / 提示 / 出牌（黄）」。
- **手机横屏**：出牌区 46px 宽牌；其余同 ①。
- **演出**：
  - 选中牌上浮 26px + 黄色外框；悬停倾斜上浮（手牌扇形相邻联动）。
  - 出牌：选中的牌依次（间隔 55ms）飞到出牌区，落地弹一下。
  - **炸弹 / 王炸**：飞行抬得更高 → 冲屏"炸！"（衬线 150px，朱红字墨边 + 金色放射光）→ 4px 屏震 → 出牌区每张牌依次再弹一下 → 两个对手半身像往后缩一下 → 上家冒气泡"啊？！"。**倍数不变**。
  - 对手"不出 / 要不起"：名牌上方气泡 1.6 秒后淡出。
  - 倒计时：≤10 秒变金，≤5 秒变珊瑚红 + 脉冲。

### 4.3 画面 ③ 结算（`landlord-3-result.html`）

- **桌面**：最后一手牌留在桌心；两个输家（或地主）名牌下方的背面小扇**翻开**成正面（40px 宽）；一张朱红"捷报"卷轴从梁下展开（460px 宽）：顶上"捷 报"、中间衬线 64px 大字"地主胜 / 农民胜"、一行"小鱼干 一人扛下两家 / 阿杰、可可 联手拿下"、一排小标签"叫分 3 · 倍数 ×3"；春天时卷轴右下再盖一枚"春"字方印；地主胜时撒红纸屑；底部「返回房间 / 再来一局（黄）」。
- **手机横屏**：卷轴 300px 宽居中偏上，最后一手在卷轴下方。
- **演出**：输家剩牌间隔 90ms 逐张翻开 → 900ms 后卷轴 700ms 展开 → 3px 屏震 → 春天时再过 500ms 盖印 + 冲屏"春天！"+ 4px 屏震。

### 4.4 手机竖屏

整页盖 `.rotate-hint`：一只手机图标循环转 90°、"请把手机横过来"（衬线 28px）、一行说明。样式照 `r2/_teahouse.css` 的 `.rotate-hint`。触发条件：`@media (orientation: portrait) and (max-width: 768px)`。

### 4.5 手牌收紧算法

照搬 `r2/_teahouse.js` 的 `fitHand`：`overlap = min(基础重叠, -(牌宽 - (可用宽 - 牌宽) / (张数 - 1)))`；桌面可用宽 900、基础 −38；横屏可用宽 400（叫分阶段 340，因为操作坞多一个按钮）、基础 −24。现有 `LandlordGamePage.tsx` 的 `computeLandlordHandOverlap` 改成这个公式，不要新写一个。

## 5. 动效与音效（四档）

| 演出 | default | reduced | minimal | off |
|---|---|---|---|---|
| 出牌飞行 | 完整弧线 500ms | 直线 300ms | 淡入淡出 150ms | 无，直接出现 |
| 炸弹冲屏 + 屏震 + 对手后缩 | 全部 | 冲屏保留、无屏震、无后缩 | 冲屏改成出牌区标签闪一下 | 无；出牌区标签写"炸弹" |
| 叫分木牌弹起 | 480ms 弹簧 | 200ms | 无，直接变金 | 无 |
| 金元宝落下 | 900ms | 400ms 直线落下 | 直接出现 | 直接出现 |
| 底牌翻开 + 飞入 | 翻开 420ms / 飞 520ms | 翻开 200ms / 飞 300ms | 直接翻开，直接出现在手里 | 同 minimal |
| 捷报展开 + 纸屑 + 春印 | 全部 | 展开保留、无纸屑、印章不放大 | 直接出现 | 直接出现 |
| 灯笼摆动 | 4.5s 循环 | 停 | 停 | 停 |
| 倒计时脉冲 | 有 | 有 | 无 | 无 |

## 7. 不照抄

- 方向稿顶部工具条（视口切换、重播、切结算情况）是预览用的。
- 方向稿里对手自动"要不起 / 不出"是演示；正式版由服务端事件驱动。
- 方向稿的「提示」按钮固定选中四张 8，是演示。现有 `LandlordGamePage.tsx` **没有**提示逻辑，所以正式版**先不做「提示」按钮**，操作坞只有「不出 / 出牌（黄）」，间距照方向稿。是否要做提示功能列入 README §5 待确认 Q4。
- 对手半身像是两套固定 SVG（阿杰 / 可可）。正式版对手是任意玩家：**用同一个半身像剪影 + 玩家颜色填衣服**，头部换成玩家头像（`UserAvatar`）裁成圆形贴在脸的位置。
