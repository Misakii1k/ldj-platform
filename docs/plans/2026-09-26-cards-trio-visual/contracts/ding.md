# Ding 视觉契约 · UNO 同系列（铃在盘心）

像素参照：`docs/ui-preview/cards-trio/r2/ding-1-play.html`（拍铃成功）、`ding-2-miss-result.html`（拍错 + 结算）
共用：`r2/_party.*`（桌布 / 圆盘 / 贴纸 / 牌 / 手牌收紧，与 UNO 同一套）、`r2/_ding.*`（铃 / 挑卡 / 质疑面板）
规则：**先读 `ding-rules.md`**。本契约所有画面都按新规则。

适用 ruleset：`bell_clash_v1`（`game/bell-clash/BellClashGamePage.tsx`）。桌面模拟版 `BellClashSimStage.tsx` **本次不改**。

## 1. 设计方向

- 隐喻：**UNO 同系列姊妹盒**。桌布 / 纸板圆盘 / 贴纸席位 / 牌框与 UNO 完全同一套组件（T2 的派对桌），只换两处：
  1. 牌背中心色块从红换成 Ding 深绿；桌布**开局是 Ding 深绿**，之后随当前色泼色（与 UNO 相同）。
  2. **圆盘正中是一只金色实体大铃**（铃身金色渐变 + 深绿底座），牌堆和弃牌分列铃的两侧。
- 档位：平面。现有 Ding 开着 `.stage-felt-3d`，**关掉**。
- 用户原话：「Ding 的整体游戏机制基本和 UNO 差不多，只不过额外多加了一个动作触发或者行为触发的东西。」

## 2. 状态模型（新规则后的视图，见 `ding-rules.md` §4）

| 字段 | 驱动的画面 |
|---|---|
| `discardTop.color` | 桌布色 / 泼色 / HUD 当前色 |
| `currentPlayerId` | 当前玩家贴纸高亮；阶段牌"轮到阿杰" |
| `handCounts` | 贴纸张数 |
| `challenge === null` | 铃在盘心，平时轻轻呼吸（2.4s 上下 3px）；**任何时候可按** |
| 本地"挑卡"态（纯客户端） | 按下铃后：铃"叮"弹一下 + 双圈金色声波 + 3px 屏震；手里短语卡上浮 30px + 黄框，其他牌压暗；手牌上方黑底提示"点一张你看到的动作"；再点铃或点空白处取消 |
| `challenge !== null` | 盘心换成**亮卡 + 质疑面板**：左边亮出的短语卡放大（桌面 140px 宽、倾斜 −4°），右边奶油卡纸面板"真的有人这么做了吗？"+ 每个投票人一枚胶囊（头像 + "…"，投票后变"有"绿 / "没做过"红，弹一下）+ 剩余秒数；铃外一圈黄色倒计时环（最后变红）；牌堆 / 弃牌 / 铃 / 阶段牌 / HUD 暂时隐藏 |
| 我是投票人 | 面板下方两个按钮：「有」（普通）/「没做过」（普通）——**这里不用黄色**，两个选项地位相同 |
| `bell_resolved { success: true }` | 亮卡飞进弃牌堆 → 泼色成这张卡的颜色 → 冲屏"抢到回合！"+ 3px 屏震 → 拍铃者贴纸高亮 |
| `bell_resolved { success: false }` | 亮卡上盖一枚珊瑚红"没人做过"方章（倾斜 −14°）→ 铃变灰左右晃 → 冲屏"拍错了！罚摸 1 张"+ 4px 屏震 → 亮卡缩小飞回拍铃者手里 → 黑底白字"+1"从牌堆飞到拍铃者 → 一张背面飞进手里；阶段牌"拍错 · 仍然轮到可可" |
| `phase = game_over` + `winners` | 画面 ③ 结算 |

## 3. 色值

- 牌面四色、纸板色：沿用派对桌 `--pt-*`。
- Ding 专属，在 `.bc-game`（现有根类）里定义一次：`--bc-ding: #146e59`（catalog berry，底座 / 牌背 / 开局桌布）、`--bc-ding-dark: #075342`、`--bc-bell-hi: #fffbe6`、`--bc-bell: #f2b92e`、`--bc-bell-lo: #b98016`、`--bc-bell-rim: #d99f22`。
- 投票胶囊：有 = `#dff3e8` 底 `#1f7a4d` 字；没做过 = `#fde3dd` 底 `var(--gp-coral)` 字。这两组也在 `.bc-game` 里定义成 `--bc-vote-ok-bg / -fg`、`--bc-vote-no-bg / -fg`。

## 4. 三张关键画面

### 4.1 画面 ① 平时 + 挑卡（`ding-1-play.html` 初始 → 点铃）

- **桌面**：与 UNO 画面 ① 同布局；圆盘正中是铃（176px），牌堆 / 弃牌向两侧拉开（间距 230px，牌 108px 宽）；阶段牌可能较长（"轮到阿杰 · 老王刚伸了个懒腰"只是演示，正式版只写"轮到阿杰"）；操作坞「摸牌 / 拍铃！（黄）」——**拍铃是本款唯一常驻黄色主按钮**；轮到我且选中了可出的牌时，出牌由点牌完成（与 UNO 相同），不另加出牌按钮。
- **手机竖屏**：铃 96px；牌 58px；间距 112px；其余同 UNO 手机布局。
- 挑卡态见 §2 表。

### 4.2 画面 ② 质疑中 + 成功（`ding-1-play.html` 点「伸了一个懒腰」之后）

- **桌面**：盘心 = 亮卡 140×208 + 质疑面板（≥260px 宽，投票胶囊 3 列）。
- **手机竖屏**：亮卡 70px + 面板 200px 横排，整体放在对手贴纸下方（底边距屏幕底 330px），不压贴纸。
- 成功演出见 §2。

### 4.3 画面 ③ 拍错 + 结算（`ding-2-miss-result.html`）

- 拍错演出见 §2。
- **结算（桌面）**：圆盘缩到 340、上移到 26%，铃在圆盘里；圆盘下缘衬线 52px 奶油白字（墨边）"可可 先出完！"+ 黑底胶囊"本局获胜"；下方 900px 宽一排 5 张奶油卡片，每张：名次 / 头像 + 名字 / 剩牌背面小扇 / 衬线 28px 剩牌张数。按剩余张数少者在前，并列同名次。底部「返回房间 / 再来一局（黄）」。
- **结算（手机）**：圆盘 220 在 20%；卡片两列，每张改成一行（名次 · 名字 · 张数），不显示背面小扇。
- 结算演出：铃自己连响三下（间隔 380ms，第一下冲屏"叮叮叮！"+ 4px 屏震）→ 卡片间隔 140ms 逐张上滑入场。
- 抽牌堆耗尽时服务端按手牌最少者判胜（可能多名胜者）：大字改成"牌摸完了 · 某某、某某 获胜"。**Ding 不计分**，卡片上只有张数。

### 4.4 牌多规则

与 UNO 完全相同（`uno.md` §4.3），直接复用 T2 的组件。验收档位 6 / 15 / 24 张。挑卡态下紧凑模式的短语卡也要上浮并让出右侧空间，保证能点到。

## 5. 动效与音效（四档）

| 演出 | default | reduced | minimal | off |
|---|---|---|---|---|
| 铃呼吸 | 2.4s 循环 | 停 | 停 | 停 |
| 拍铃（压扁 + 声波 + 屏震） | 全部 | 压扁保留、声波一圈、无屏震 | 只压扁 | 无动画，铃变色表示按下 |
| 亮卡飞到盘心 | 460ms 放大到 1.6 | 250ms | 直接出现 | 直接出现 |
| 投票胶囊弹出 | 260ms 弹簧 | 淡入 | 直接变 | 直接变 |
| 成功：飞入弃牌 + 泼色 + 冲屏 | 全部 | 飞 250ms、泼色 280ms、冲屏保留 | 直接落牌、直接换色、阶段牌写"抢到回合" | 同 minimal |
| 拍错：盖章 + 铃晃 + 冲屏 + 卡飞回 + 罚牌飞 | 全部 | 盖章不放大、无晃、冲屏保留、飞 250ms | 盖章直接出现、阶段牌写"拍错 · 罚摸 1 张"、卡直接回手里 | 同 minimal |
| 结算铃连响 | 3 下 + 冲屏 | 1 下 | 无 | 无 |

音效：拍铃"叮"（现有 `bell-clash/stage/audioCues.ts` 的铃声）；成功"叮 + 上扬"；拍错"低沉错误音"+ 震动 `[40, 50, 40]`；投票每票一声轻"嗒"。

## 7. 不照抄

- 工具条、"② 看结算"、手牌张数切换是预览用。
- 方向稿里投票是脚本定时写死的，正式版由服务端 `challenge.doubtIds / confirmIds` 驱动。
- 方向稿里老王头上的"（伸了个懒腰）"气泡是为了让演示看得懂，**正式版没有这个气泡**——动作发生在线下，App 不知道。
- 方向稿的"拍铃"按钮与点铃本身效果相同；正式版两者都保留。
