# 01 · 视觉契约：狼人杀 · 深夜剧场（AI 法官模式）

按 `docs/design-spec.md` §11.2 六节。像素参照是 README 表里的四个定稿方向稿；本文与方向稿冲突时，**以方向稿为准**，并在 PROGRESS 记下差异交回用户。

---

## 1. 设计方向

- **一句话隐喻**：深夜的老剧院——玩家坐在左右两排包厢里，中央是一座带红幕的台口舞台，谁发言追光就打在谁身上。
- **表皮**：深色悬疑（`DESIGN-DIRECTION.md` C2 / C12）：暗色底、1–1.5px 金色细边、贴纸阴影；**不用**粗墨边 + 硬投影。
- **唯一主题**：只保留剧场一套（用户 2026-09-26「最后一个主题只要一套就行了，要剧场」）。**移除**森林（木刻日 / 月蚀夜）与顶栏主题切换。
- **昼夜**：始终暗场，靠灯光分昼夜——白天红幕拉开、脚灯亮、暖色追光；夜晚红幕合拢、脚灯熄、只剩冷色月光。不再有奶油浅底的"白昼剧场"。
- **构图**：C10 左右两排席位 + 中央舞台 + 底部操作区（定稿 A「两翼包厢」）。
- **档位**：平面 2.5D（CSS 渐变 + 投影），不上 3D。
- **对标**：项目内 = 榴莲（完成度）；项目外 = Balatro，只取打击感（飞行、弹跳、计数、屏震），不取霓虹与像素风（C13）。

## 2. 状态模型（驱动画面的字段）

全部来自现有 `WerewolfPresentationModel`（`packages/client/src/game/werewolf/presentation.ts`），不新增服务端字段。

| 字段 | 画面变化 |
|---|---|
| `timeline.period`（无权威时间线时回退 `phase` / `nightStage`，已由 `resolveThemePeriod` 实现） | `day` → 红幕拉开 + 脚灯亮 + 暖追光；`night` → 红幕合拢 + 脚灯熄 + 冷月光 + 两侧暗角 |
| `phase` | 决定中央舞台放哪个"场景"（见 §4 场景表） |
| `seats[]`（`alive` `isSelf` `isSpeaking` `isWolfTeammate` `idiotRevealed` `targetActions` `isMyTarget` `seerResultTeam` `revealedRoleLabel`） | 票根卡的状态类（见 §4.1 票根状态表） |
| `activeSpeakerSeat` / `seats[].isSpeaking` | 中央发言者头像、名字大字、追光落点；交麦飞行的起止席位 |
| `deadlineAt` / `timelineTimer`（**有 deadlineAt 的阶段**：`role_reveal` `night` `hunter_shot` `discussion` `free_discussion` `voting` `runoff_voting` `vote_result` `last_words`） | 中央倒计时环；≤10 秒变橙，≤5 秒变红 + 脉冲 |
| `self.role` `nightStage` `timeline.role` | 入夜时舞台中央放哪个身份插画、是否是"你被唤醒"还是"闭眼等待" |
| `self.wolfTeammateIds` `self.wolfVotes` | 狼人视角：队友票根小狼爪 + "同伴 · 选了 N 号" |
| `self.seerResults` | 预言家视角：被查验的票根翻面变绿（好人）/ 红（狼人） |
| `self.nightVictimId` `self.witchSaveUsed` `self.witchPoisonUsed` `self.witchSaveDecision` | 女巫视角：被刀者票根红光；解药 / 毒药两个药瓶按钮的可用态 |
| `self.lastGuardTargetId` | 守卫视角：该票根标"昨晚已守"、不可选 |
| `voteProgress`（`submitted` `expected` `hasVoted` `isRunoff` `isRunoffCandidate`） | 投票中央：票箱 + 已投进度点（只显示人数） |
| `voteLedger`（`rows[].count` `abstained` `outcome` `exiledSeat`，仅 `vote_result` 阶段有值） | 唱票飞票动画、票根上的票数徽章、放逐撕票 / 平票加赛 / 白痴翻牌 |
| `reveal` + 服务端 `players[].revealedRole` `exitReason` + `reveal.voteHistory`（仅 `game_over`） | 终局：票根逐张翻面、胜负大字、胜方插画并排、底部每日小条 |
| `winner` | 胜负大字文案与配色 |

**隐私红线（C18，读自 `packages/games/werewolf/server/v2/rules.ts`）**：
- 只公开每人得票数与弃票数，**不公开谁投了谁**。唱票动画的票只从票箱飞出，不从投票人席位飞出。
- 局中不公开出局者身份与死因；票根出局态只写"出局"，终局才写死因（`exitReason`）与身份。
- 他人身份只在 `game_over` 进入 DOM。

## 4. 关键画面

每个画面都以对应方向稿为像素参照，下面只写**结构与规则**，尺寸以方向稿为准。

### 4.0 通用骨架（所有阶段不变）

| 区域 | 1280×800 | 390×844 |
|---|---|---|
| 顶栏 | 左：「狼人杀」衬线 + 胶囊「第 N 天 · 白天 / 第 N 夜 · 🌙」+「存活 X 人」；右：身份 / 记录 / 规则 / 交流 / 设置圆形图标钮（现有功能保留） | 同左但不显示存活数；图标 32px |
| 左右包厢栏 | 各一列，宽约 250，高约 610，深红渐变底 + 金色细边 + 内虚线；席位 `ceil(n/2)` 在左、其余在右，**右侧自下而上排**（座位号绕场一圈） | 各一列宽约 86；紧凑竖版票根 |

### 4.1 剧场票根席位卡（`_ticket.css`，所有画面共用）

- 结构：左侧票根（64px，衬线大号座位号 + 小字 SEAT）｜齿孔虚线（上下两个半圆缺口）｜右侧头像 + 名字（加粗）+ 状态行。
- 手机紧凑版：上票根（号码）/ 横向齿孔 / 下头像 + 名字 + 状态。

| 状态 | 表现 |
|---|---|
| 默认 | 深红渐变底，金色 28% 细边 |
| 你（isSelf） | 金色虚线边 + 顶部「你」小胶囊 |
| 发言中 | 票根整块变金、座位号变深色；卡片金边 + 暖光晕 |
| 可点（有 targetActions） | 悬停上浮 2px + 微倾斜 + 边框提亮 |
| 已选（isMyTarget） | 金边 + 光晕 + 对应印章（夜间）/ 黄色选中（投票） |
| 出局（局中） | 半透明灰化；票根左上角撕掉（锯齿 clip-path）+「作废」；状态行只写「出局」，**不写死因** |
| 终局揭晓后 | 票根换成身份小插画；好人绿底 / 狼人红底；状态行「身份 · 死因或存活」；胜方金光、败方 62% 透明 |

### 4.3 发身份（`role_reveal`）

- 中央：kicker「第 1 夜之前 · 查看你的身份」；一张牌背（`/assets/roles/card_back.png`，桌面约 210×290，手机约 150×206）。
- 点牌 → 3D 翻面（Y 轴 640ms 回弹）→ 正面：左上阵营胶囊、身份插画（`WEREWOLF_ROLE_ARTWORK`）、身份名衬线大字；翻开瞬间一道扫光。
- 牌下：技能说明一句（`WEREWOLF_ROLE_DETAILS[role].skill`）；「已确认 X / N 人」+ 进度点（`confirmedRolePlayerIds`）。
- 底部黄色主按钮「我记住了」→ 发 `confirm_role`，牌盖回牌背，文案变「已确认，等待其他人」。
- 失焦 / 切后台自动盖回牌背（沿用现有隐私逻辑）。

### 4.4 入夜 / 夜间行动（`night`）

- 夜幕：两侧暗角（中央留一束冷月光），红幕合拢，脚灯熄。
- 中央：当前行动身份的插画（`timeline.role` 或 `nightStage` 对应 `WEREWOLF_ROLE_ARTWORK`），外圈冷月光晕；kicker「第 N 夜 · 你被唤醒」；大字「狼人请睁眼」等；说明一行；倒计时环（冷蓝色）。
- **你被唤醒时**（你的身份 = 正在行动的身份）：

| 身份 | 可点票根 | 选中表现 | 主按钮 | 次要按钮 |
|---|---|---|---|---|
| 狼人 | 存活的非狼玩家（规则允许刀任何人时以 `targetActions` 为准） | 红色 🐾 圆形印章砸下 | 「确认袭击 · N 号」 | 无 |
| 预言家 | 以 `targetActions` 为准 | 蓝色 👁 印章 | 「查验 · N 号」 | 无 |
| 女巫 | 先点中央「💧 解药」或「☠ 毒药」；选毒药后才可点票根 | 紫色 ☠ 印章 | 「用解药救 N 号」/「向 N 号下毒」 | 「今夜不用药」 |
| 守卫 | 以 `targetActions` 为准；`lastGuardTargetId` 标「昨晚已守」且不可点 | 青色 🛡 印章 | 「确认守护 · N 号」 | 「空守」 |

  - 狼人：队友票根右上小狼爪，状态行「狼队友」或「同伴 · 选了 N 号」（`wolfVotes`）。
  - 女巫：被刀者（`nightVictimId`）票根红光 + 状态「今晚倒下」；中央说明「今晚 N 号 XXX 倒下了」；用过的药瓶划线置灰。
  - 预言家确认后：该票根的票根部分 Y 轴翻面，好人绿 / 狼人红，状态「查验：好人 / 狼人」；中央说明「N 号是 好人 / 狼人」。
  - 确认后：中央说明变「已锁定 N 号，等待同伴」等；底部「已完成，请闭眼」；印章保留。
- **闭眼等待时**（不是你的回合）：中央插画压成黑色剪影（亮度 8% + 冷光描边），大字「狼人正在行动」等，说明「你是 村民，今夜无需操作」；所有票根压暗到 55%（你自己 90%）；底部无按钮。
- 选目标交互：**直接点两侧票根**，不再弹出 `ww-target-dialog`（多动作席位例外：`targetActions.length > 1` 时仍可弹窗）。

### 4.5 白天发言（`discussion` / `free_discussion`）

- 中央（定稿 A2 = A 原版发言者）：kicker「正在发言」；圆形头像（桌面 150 / 手机 96，金边 + 暖光晕）；名字衬线大字（桌面 52 / 手机 30；是你时写「轮到你了」）；「N 号 · 第 k / 存活数 位发言」；倒计时环（桌面半径 36 / 手机 26）。
- 票根：发言中金票根；下一位状态「下一位」；已发言「已发言」；未发言「待发言」。
- 只有轮到你时出现黄色主按钮「发言完毕 · 交麦」（`finish_speech`）。
- 交麦演出：金色 🎙 圆球从当前发言者票根沿弧线飞到下一位票根（560ms），落点票根回弹、轻屏震，中央名字砸入（slam）。
- `free_discussion`：中央 kicker「自由发言」，大字「自由讨论」，说明「已准备投票 X / N 人」；主按钮「准备投票」（`ready_vote`）。
- 移除：森林木刻 SVG、月蚀星轨、`art-caption`、`.next` 进度条、中央「上一轮票型」按钮（票型记录移到顶栏 📜 图标）。

### 4.6 投票 / 唱票 / 放逐 / 遗言

① **投票**（`voting` / `runoff_voting`）：中央「放逐」木票箱（金边）；大字「投出你心中的狼」/ 选中后「你投给了 N 号」；「已投 X / Y 人 · 可以弃票」+ 进度点（`voteProgress`）；倒计时。点票根选人（不能选自己，以 `targetActions` 为准）→ 黄色「投给 N 号」；次要「弃票」。其他人票根状态只写「已投 / 投票中」，不写投给谁。加赛轮：候选人票根橙边「平票 · 加赛候选」，候选人自己看到「你是候选人，本轮不能投票」且无按钮。

② **唱票**（进入 `vote_result`）：大字「正在开箱…」；按得票**从少到多**逐张播放：一张选票从票箱飞到被投者票根（420ms 弧线 + 旋转），票箱轻晃，票根右侧金色衬线票数徽章 +1 并弹跳。播完大字「N 号得票最多」，说明「最高 X 票 · 弃票 Y」，最高票票根金光锁定。

③ **结果**（同在 `vote_result`，唱票结束后）：
  - `eliminated`：被放逐者票根**从中间横向撕开**，下半张旋转下落淡出（600ms），上半张微倾后淡出；轻屏震；原位留红色虚线空位「已放逐」；中央大字「N 号 XXX 被放逐」，说明「得票 X · 身份将在终局揭晓」。
  - `tie`：两名（或多名）候选人票根橙边；大字「进入加赛」，说明「N 号、M 号成为候选人，候选人本轮不能投票」。
  - `idiot_saved`：不撕票；该票根盖白痴印章（插画 `idiot.png` 小图），大字「N 号翻牌：白痴」，说明「免于放逐，失去投票权」。（方向稿未画，按本条实现；样式复用印章。）
  - `no_votes` / `runoff_tie`：大字「无人出局」，说明「全员弃票」或「加赛仍平票」。
  - 猎人被放逐：先按 `eliminated` 演完，再进入 `hunter_shot`（按 §4.4 结构：中央猎人插画，猎人本人点票根盖 🎯 印章 + 「开枪 · N 号」/「不开枪」；其他人闭眼等待态文案「猎人正在决定」）。

④ **遗言**（`last_words`）：被放逐者票根恢复显示并被追光锁定（金边 + 大光晕）；中央 kicker「遗言」+ 他的头像 + 名字大字 + 倒计时；是你时主按钮「遗言结束」（`finish_last_words`）。

### 4.7 终局揭晓（`game_over`）

- 顺序：先按座位号逐张翻票根（每张 X 轴翻转 460ms，间隔约 300ms）：座位号换成身份小插画，好人绿底 / 狼人红底，状态行「身份 · 死因（按 `exitReason`：被袭击 / 被毒 / 放逐 / 猎人带走 / 掉线）或存活」。
- 全部翻完：胜方票根金光、败方 62% 透明；中央胜负大字盖章入场（`--gp-font-display`，桌面 64 / 手机 34；好人胜绿色辉光 / 狼人胜红色辉光）+ 轻屏震；说明「所有狼人都已出局 / 好人阵营已无法翻盘 · 你是 XX，你赢了 / 你输了」；下方**胜方身份插画并排**（同身份合并一张，下写「3、7 号 预言家」这样的座位号）。
- 底部舞台下方一条每日小条（`reveal.voteHistory` + 死因）：每天一格，如「第 1 天 · 12 号 6 票放逐」，狼人座位号红字标「(狼)」。手机两列网格。
- 底部：黄色「再来一局」（沿用现有返回房间逻辑）+ 次要「查看完整复盘」（打开现有 `GameOverReveal` 详情）。

## 5. 动效与音效（四档：`html[data-motion-level]` = `full / reduced / minimal / off`）

只动 `transform` / `opacity`；单次 ≤ 600ms（唱票、终局逐张翻属逐项累计，例外）。

| 演出 | full | reduced | minimal | off |
|---|---|---|---|---|
| 昼夜切换（红幕开合、脚灯、追光冷暖） | 红幕 900ms 滑动；灯光 700ms 渐变 | 同 full 但 400ms | 红幕与灯光直接切换，保留 200ms 淡入 | 直接切换 |
