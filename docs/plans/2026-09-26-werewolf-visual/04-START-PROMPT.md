# 04 · 交给执行模型的提示词

## 首次开工（复制这一段）

你接手 D:/项目 的狼人杀剧场视觉改造（AI 法官模式）。设计已由用户定稿，你只负责照做，**不做任何新的视觉决定**。

先只读这几个文件：
1. D:/项目/docs/plans/2026-09-26-werewolf-visual/README.md
2. D:/项目/docs/plans/2026-09-26-werewolf-visual/PROGRESS.md
3. D:/项目/docs/plans/2026-09-26-werewolf-visual/02-TASKS.md 中第一个 TODO 任务那一节

然后按该任务卡执行。视觉任务开工前，用浏览器打开卡片里写的定稿方向稿（D:/项目/docs/ui-preview/werewolf/directions/），它就是像素参照；尺寸、颜色、动效时长照方向稿与 01-CONTRACT.md 抄，不要自己发挥。

规则：
- 一轮只做一个任务；只改卡片白名单里的文件。
- 遇到方向稿没画、计划也没写的细节，停下，在 PROGRESS.md 的「待用户决定」写清问题，交回用户。
- 做完跑卡片要求的命令，把命令与退出码写进 PROGRESS.md；失败就修到通过，不许删断言或放宽隐私。
- 视觉好不好只由用户看图判定。你只能写"待用户看图"，不能写 PASS / 达标 / 已对齐。
- 回复不超过约 250 字：做了什么、命令结果、未通过项、下一个任务。

## 后续继续（短提示）

继续 D:/项目/docs/plans/2026-09-26-werewolf-visual/PROGRESS.md 中下一个 TODO 任务。只读 02-TASKS.md 对应一节、01-CONTRACT.md 被引用的小节和对应方向稿。遵守白名单，跑卡片命令，更新 PROGRESS。回复 ≤250 字。

## 独立复核（不改代码，可选）

只复核刚完成的任务 Wxx：读任务卡、本次 diff、命令日志、对应方向稿。检查：是否超出白名单；是否泄露隐私（谁投了谁 / 局中身份 / 终局前他人身份）；同视口黄色按钮是否 >1；是否有新字面量色 / 非契约断点；是否残留森林主题；夜间 / 投票是否仍是点席位立即发送。输出 ≤5 条具体问题（文件 + 场景 + 影响），没有问题就说明核对了哪些。
