RollingNumber 数字滚动动效

iOS 26 风格 · 逐位翻动 + 方向感知 + 进位联动 + 模糊滑入 · 全部使用 --gp-* 令牌

① 结算大分数

典型场景：狼人杀 / 斗地主结算。数值只动变化位，进位时相邻位一起滚。

② 倒计时

递减时数字从上方滑入，方向与数值变化一致。≤5 秒切珊瑚红紧迫态。

③ 胶囊徽章 · 就绪人数

小尺寸场景。多个数字独立滚动，分隔符 "/" 静止。

④ 统计面板 · 多数值同步变化

多个数字同时变化时，各自独立动画，互不等待。带千分位分隔符。

实现要点（供确认后落地参考）： 每一位数字是独立的 .rn__digit 容器，内部叠放旧/新两个 .rn__glyph； 变化时旧字向变化反方向滑出、新字同向滑入，同时叠加 blur(2.5px) 与透明度过渡。 未变化的位完全不动。整体在变化瞬间加 scale(1.06) 轻微呼吸。 时长/缓动走 --gp-dur-phase / --gp-ease-standard，并遵守 data-motion-level 四档降级。 落地时封装为 React 组件 <RollingNumber value={n} />，放在 shared-ui/。
