斗地主 / UNO / Ding · 方向稿（第 1 轮）

世界已按你的选择定下：斗地主 = 老茶馆八仙桌，UNO = 糖果色纸板游戏盒，Ding = UNO 同系列姊妹盒。三款都是浅色粗墨边。每款内部的几稿在构图上拉开差异，画的都是"轮到你出牌"这一刻。

斗地主 · 老茶馆八仙桌

固定数据：你是地主「小鱼干」剩 14 张，上家阿杰刚出对 K，底分 3 × 倍数 6。

A八仙桌俯视从正上方看整张桌子，桌心红纸垫 + 盖碗茶；对手在左右两侧名牌 ｜ 最像"一屏总览" B茶馆正堂第一人称坐在桌前，桌面透视；远处梁、灯笼、对联、牌匾；对手是坐在对面的半身人像 ｜ 环境最足 C水牌对垒顶上一面茶馆水牌当计分板（底分 × 倍数 大字），下方长条桌地主 / 农民两阵对垒 ｜ 计分最突出

UNO · 糖果色纸板游戏盒

固定数据：6 人局，你剩 7 张（含反转、跳过、+2、变色、+4），可可和糯米只剩 1 张。

A打开的游戏盒俯视一只打开的纸盒，盒壁 + 隔层就是布局：对手各占一格，中央大格是牌堆和当前颜色 B整屏色块当前颜色就是整张桌布，换色时从牌堆向外泼满全屏；纸板圆盘居中，对手贴纸环绕一圈 C立起的盒盖舞台盒盖立在后面当背景墙（大 LOGO + 四色条纹），盒底斜放当舞台；对手排成一行"出场顺序"，反转时箭头整体掉头

Ding · UNO 同系列姊妹盒

与 UNO 同款纸盒和牌框，主色换成 Ding 原有的深绿。两稿只在"铃放哪、短语怎么冲屏"上不同。固定数据：你手里有绿色短语卡「伸了一个懒腰」。

A铃在盒心铃放在中央大格正中，是全场唯一焦点；短语横幅压在铃正上方，10 秒倒计时环绕着铃 B铃在手边盒子中央只放大号弃牌；铃装在盒外右下角专属底座上，紧挨你的手牌；短语打出时一条胶带横幅斜贴满整个盒子
每稿都可以试：顶部切换 桌面 / 手机 ｜ 点手牌选中（悬停会倾斜上浮）｜「重播」恢复初始。
斗地主：点「提示」选中四张 8 → 点黄色「出牌」看炸弹演出（飞牌 + 冲屏"炸！"+ 屏震 + 倍数翻倍）；点工具条「翻底牌」看底牌翻开。
UNO：直接点手牌出牌——反转 / 跳过 / +2 / +4 各有冲屏；变色牌和 +4 会弹选色盘；点「摸牌」看牌从牌堆飞回手里。
Ding：先点工具条「① 阿杰打出短语卡」开拍铃窗口，再拍铃（点铃本身或按钮）——你手里有同色短语卡，会"叮"一声抢到回合并自动打出。
