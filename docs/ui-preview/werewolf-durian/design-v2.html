体验优化后的狼人杀对比上一版

01 · 轻边框

大多数容器由 2.5–3px 粗黑线改为 1px 边线。实体阴影保留在重要操作，降低全屏控件争抢注意力的问题。

02 · 少量强调

黄色从全局默认变为可选强调。当前玩家与主操作最亮，存活、出局和辅助记录各有明确层级。

03 · 同规则，不同情境

共用 12px 控件圆角、至少 44px 触控区域及文字对比度标准。游戏主题主要通过插画和桌面色表达。

这是设计系统候选稿。狼人杀已应用优化方案；左侧暖纸组件为方向示例，榴莲链接仍指向现有版本。正式项目样式尚未替换。
