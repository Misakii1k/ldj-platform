# UI 设计约束与确认状态

本文件记录用户明确偏好和设计候选，不把 Agent 自己的建议写成用户批准。以实际 HTML 配合本文件理解效果。

## 当前接手基准与定稿状态

用户已正式拍板方向通过：
1. **狼人杀三主题同时搭载可切换**（取代旧记录“没有 B 方案”）：**A 林中木刻（woodcut，默认）**、**B 月蚀星轨（eclipse）**、**C 赤幕剧场（theatre）** 三套主题全部搭载入生产，三主题共用左右席位与舞台核心布局，切换入口统一置于顶栏，玩家偏好持久化至 `localStorage`。
2. **榴莲设计基准**：以 `durian.html` 为基准。牌面数量允许显示数字（开启 `showBadge`），大数字使用 Georgia 衬线字体（小辅助字保持无衬线），数量位于水果下方。默认采用紧凑总览（四视口全屏一屏容纳）；舒展模式在超小屏（360×640）允许自然纵向滚动 127px，不强行压缩以捍卫 44px 最小触控区与可读性。
3. **朝外展示端定位**：`display.html` 语义正式定为**「对外展示牌」**（实时展示房间内正在玩什么 / 进行到哪 / 怎么加入 + 房间号 + 二维码）。

## 用户明确偏好

- 先 HTML 预览，再正式开发，节省 token 和返工。
- 界面有艺术感和识别度，同时属于同一个桌游项目。
- 狼人杀玩家放在左右两侧；不要必须上下滑动才能看到玩家。中间是当前发言/阶段，底部是操作。
- 榴莲桌面尽量一屏展示。不能以缩小、折叠、截断关键文字作为代价。
- 榴莲自己的回合用可收起的操作弹窗；桌面留给水果牌和累计需求。
- 水果名称与大数量上下排，避免横向挤占。
- **大数字用原来的 Georgia 衬线数字**；小字号辅助数字继续用正文无衬线体。这是最新明确指示，不要再次统一成无衬线大数字。

## 榴莲当前基准

奶油纸底、果绿、芒果黄、本地水果 SVG、卡纸感。最新仍用原项目纸卡控件，不曾全量套用狼人杀 Design V2。

- 当前基本色：纸底 `#fff4df`，表面 `#fffdf7`，正文 `#292722`，辅助 `#575147`，绿 `#08715d`，黄 `#f7c84b`。
- 数字变量：`--d-numeral-font: Georgia, 'Times New Roman', serif`。
- 使用范围：回合大数字、牌面数量、需求总数、抽牌数量、结算大罚分、历史牌数量。回合数保留原先斜体；多数数量用 700 正体。
- 小号位、罚分摘要、表格辅助数字保留正文；不要为了字体需求放大所有数字。
- 数量仍在水果下方，字体修改不得撤回新的纵向结构。
- 默认紧凑总览；手机 7 人展示 6 张他人牌，3 列 × 2 行，本人隐藏牌单独一条。舒展模式为 2 列 × 3 行，可能需要少量滚动。短横屏另有压缩排版。
- 長昵称完整换行、身份不能泄露、主按钮至少 44px。回合弹窗可滚动，但底部确认按钮应可达。

## 工程和可访问性底线

- 正文/普通控件对比度至少 4.5:1，大字至少 3:1，重要状态尽量 7:1。
- 图像背景上文字要有稳定底色，不能把低对比度当“高级灰”。
- 宽度断点仅 380/480/640/768/1024/1280px；高度仅 520/620px。
- 不依赖在线字体、素材服务；不新增框架；不默认播放持续动画和声音。
- Georgia 为系统字体，缺失时回退 Times New Roman/serif；不要声称所有设备像素一致。
- 每次视觉验收保留明确尺寸、场景、设计版本；现有截图未经本次核实，不能冒用为最新版。
