# 狼人杀语音接入验证记录

## 本次结果

- 实盘目录逐文件核对：130 个 WAV，各有唯一目录记录、SHA-256、采样率、声道与 RIFF 数据时长。
- 80 段可安全公放：75 段有自动场景映射，另外 5 段作为同义/替代主持点播；80 段均经过可达条件验证。
- 17 段涉密录音、33 段未支持规则录音不进入播放白名单。原音频全部保留。
- 音频—场景对照及未接入原因见 `docs/werewolf-voice-coverage.md`。

## 使用方式

真人主持控制台 → **语音点播** → 选择分类/搜索、实际玩家号码、播放位置。
默认仅本机；全房间遵守各设备显式静音及音量。浏览器限制出声时点击“点击开启声音”。
点播/停止会冻结运行中的自动辅助，不会在音频结束时自行恢复。公开死亡等结果须先确认，点播不修改存活状态。
旧对局没有可信房间座位映射时，非号码录音仍可用；号码点播需重新开局。原资源只覆盖 1—12 号，不伪造 13 号录音。

## 已通过的验证

- `npm run typecheck`
- 378 项单元/契约测试：狼人杀全部规则与时间线、狼人杀客户端、shared 全部契约测试、主持会话与恢复测试。
- 5 项浏览器 E2E：`e2e/werewolf-voice.spec.ts`、`e2e/werewolf-moderator.spec.ts`。
  - 真实原生 Audio.play 成功（不是只统计调用）。
  - 两设备本机/房间作用域、真实座位号、静音、停止/重播、原子暂停。
  - 越权与涉密请求拒绝；结束后点播仍同步，数据库结算记录仍为 1。
  - 模拟浏览器 NotAllowedError 后点击解锁；重复快照不重播；重新加载接续有效片段，过期内容不补播。
  - 390×844 手机竖屏、844×390 低高度横屏、1280×800 桌面布局无横向溢出；控件可见；语音面板计算样式对比度均不低于 4.5:1。
- 相关新增核心代码与 E2E 的定向 ESLint 通过。
- `npm run build` 通过；`packages/client/dist` 已同步（保留项目现有大 bundle 警告）。
- 功能路径 `git diff --check` 通过。

日志与三尺寸截图：`output/werewolf-voice-*`。
